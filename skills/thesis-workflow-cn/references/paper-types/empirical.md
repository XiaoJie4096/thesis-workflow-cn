# 实证研究 写作模板

## 适用范围

判断依据：论文用可观测数据检验变量之间的关系、组间差异、作用条件或政策效果，正文按"问题→理论与假设→研究设计→实证结果→结论建议"展开，主要结论来自描述统计、回归或结构方程等模型的估计结果。若只描述现状并提出对策、没有数据检验，归"案例分析对策研究"类；若核心是人为操纵条件、设置实验组和对照组，归"实验研究"类。问卷只是收集数据的方式，用问卷做经营调查和用量表做心理关系分析，按各自对应的变体写。

包含的子类：
- 企业微观计量：上市公司或企业层面数据，检验某一因素对企业结果的影响。
- 宏观或区域面板计量：国家、省、市或行业的面板数据，常含指标测度、空间或门槛模型、政策冲击评估。
- 问卷调查与中介调节模型：针对某一群体发放量表，检验主效应、中介效应和调节效应。
- 其他：农户截面调查、效率测算等，按最接近的变体写。

本科论文围绕一个中心问题，用一套数据完成一组检验。主骨架按企业和区域计量的通用流程写，问卷路线的差异写成变体。

## 章节骨架

"必有"的章节每篇都写，"常见"的章节按题目取舍。一项内容可以独立成节，也可以并入相邻节。

主骨架（5 章，17 节）：

第1章 绪论（必有）
- 1.1 研究背景与问题提出（必有）
- 1.2 研究意义（必有）
- 1.3 研究内容、方法与技术路线（必有，含论文结构安排）

第2章 文献综述与理论分析（必有）
- 2.1 核心概念与理论基础（必有）
- 2.2 文献综述与述评（必有）
- 2.3 理论分析与研究假设（必有）

第3章 研究设计（必有；篇幅紧时可作为第4章的前三节）
- 3.1 数据来源与样本选择（必有）
- 3.2 变量定义与测量（必有）
- 3.3 模型设定与分析方法（必有）

第4章 实证结果与分析（必有）
- 4.1 描述性统计与相关分析（必有）
- 4.2 基准回归结果（必有）
- 4.3 稳健性检验与内生性处理（企业、区域必有）
- 4.4 异质性与机制分析（常见）
- 4.5 结果讨论（常见；不设时把讨论写进 4.2–4.4 各节末尾）

第5章 结论、建议与展望（必有）
- 5.1 研究结论（必有）
- 5.2 对策建议（必有）
- 5.3 研究局限与展望（必有）

第4章的节按实际用到的方法命名。没有用到的方法不设节，例如未做内生性处理时 4.3 改名"稳健性检验"，未做机制检验时 4.4 改名"异质性分析"。

每章末不单设"本章小结"节，在最后一节末尾用一段话回收本章结论。

合并做法：正文不足 12000 字时，把第3章并入第4章作为前三节，章名改为"研究设计与实证分析"；或把 4.5 拆进 4.2–4.4 各节末尾。减少节数，不压低单节字数。

变体 A：企业微观计量
主骨架即可。4.3 必有，常用替换被解释变量、替换解释变量、调整样本区间、剔除特殊样本、工具变量或倾向得分匹配中的两到三项。4.4 写一到两项按企业产权、规模、行业或地区的分组，再加一项渠道检验。多个结果变量时只保留一个主结果，其余作为扩展写在 4.4。

变体 B：宏观或区域面板计量
自建综合指数时，3.2 写指标体系和测度方法，4.1 改为"测度结果与描述统计"，写时间趋势和区域差异，可配一幅趋势图或分布图。4.3 必有。4.4 按东中西部或经济发展水平分组；问题涉及空间溢出时写空间计量，涉及非线性时写门槛模型，涉及政策冲击时写双重差分。这几种模型对应不同问题，一篇只选与问题对应的一种。

变体 C：问卷调查与中介调节模型
第3章改为"研究设计与数据收集"：3.1 问卷设计与量表来源，3.2 预调查与正式调查，3.3 分析方法。第4章改为：4.1 样本特征与描述统计，4.2 信效度检验与共同方法偏差检验，4.3 相关分析与主效应检验，4.4 中介效应与调节效应检验，4.5 结果讨论。4.5 常见，独立成节。人口学变量的组间差异检验常见，可写在 4.1。

变体 D：截面调查或效率测算
第3章写调查区域、抽样方式和样本户数；效率测算类在 3.3 写 DEA 或随机前沿模型，4.1 报告测算结果，4.2 起写影响因素回归。

## 字数分配

按正文 12000 字分配，17 节平均约 700 字。文献和理论推导压缩，篇幅给研究设计和实证结果。

| 章 | 占比 | 参考字数 | 浮动范围 |
|---|---|---|---|
| 第1章 绪论 | 15% | 1800 | 1500–2300 |
| 第2章 文献综述与理论分析 | 20% | 2400 | 1800–3000 |
| 第3章 研究设计 | 18% | 2150 | 1800–2700 |
| 第4章 实证结果与分析 | 32% | 3850 | 3000–4800 |
| 第5章 结论、建议与展望 | 15% | 1800 | 1500–2200 |

- 每节不少于 600 字。某章取到浮动下限、平均每节不足 600 字时，按合并做法减少节数，例如 1.2 并入 1.1、5.3 并入 5.2。
- 第4章内部参考：4.1 约 650，4.2 约 1000，4.3 约 800，4.4 约 800，4.5 约 600。
- 某项扩展不适用时，把它的字数移回 4.2 和 4.5。
- 问卷变体把稳健性检验的字数给信效度检验和中介调节检验。

## 各章写法

### 第1章 绪论

任务：从现实现象提出一个中心问题，说明它为什么值得用数据检验，本文用什么资料和方法回答。

1.1 研究背景与问题提出
1. 用两到三条统计事实或政策事实交代研究对象的处境，写明时间、范围和来源。
2. 指出事实之间的矛盾或已有解释的分歧。
3. 收敛到一个中心问题，写成"X 是否影响 Y、如何影响、在什么条件下影响"。
4. 把中心问题拆成两到三个可由数据回答的子问题。
- 可配一幅趋势图或对比图，只画与中心问题直接相关的数据。

1.2 研究意义
1. 理论意义：写本文在概念口径、测量方法、样本对象或关系证据上补充了什么。
2. 实践意义：写结论能帮哪类决策主体（政府部门、企业、学校、个人）做出什么判断。
3. 每条意义对应一处已有研究的不足。

1.3 研究内容、方法与技术路线
1. 按子问题顺序列研究内容，每项写使用的资料、采用的方法和得到的证据。
2. 列研究方法，每种方法写它解决什么困难，例如文献研究法界定概念、面板回归控制个体差异、Bootstrap 检验间接效应。
3. 画技术路线图：问题提出→理论分析→研究设计→实证检验→结论建议。
4. 用一段写论文结构，每章一句，交代该章内容和前后衔接。
5. 可加一段"可能的创新点"，写一到两条，落到样本、测量或视角上。
- 配图 1 幅（技术路线图）。

### 第2章 文献综述与理论分析

任务：界定概念，梳理已有研究，借助理论推出可检验的假设。

2.1 核心概念与理论基础
1. 每个核心变量对应一个概念，先列两到三种代表性定义。
2. 比较各定义的范围和适用情境，说明本文采用哪一种口径。
3. 把概念落到可观测对象和测量方式，说明数值高低的含义。
4. 相近术语写清差别，例如"数字化转型"与"信息化"。
5. 选一到两个理论，每个写核心观点、在本研究情境中对应的环节、能推出的变量关系。
- 概念和理论较多时，用三级小节分开写。

2.2 文献综述与述评
1. 按"解释变量的研究→被解释变量的影响因素→二者关系的研究"三个主题组织。
2. 每个主题先概括共同结论，再用代表性研究说明用了什么数据、什么方法、得到什么结果。
3. 正向、负向、非线性和不显著的结论并列写，用样本、时间或测量差异解释分歧。
4. 国内外研究按主题合写，不分成两份名单。
5. 述评先归纳已有共识，再提出一到三项本文能回应的不足，例如测量口径单一、缺少某类样本、未检验某一作用条件。
6. 每项不足对应本文后面的一项工作。
- 需要比较测度方法时，配一张对比表（口径、数据要求、适用性、本文取舍）。

2.3 理论分析与研究假设
1. 沿"条件→过程→结果"写主效应机制，用 2.1 的理论解释每一步。
2. 存在相反作用方向时，分别写理由，再说明本文预期哪一方占优。
3. 提出主效应假设 H1。
4. 按同样写法推出机制或调节假设 H2、H3，每条只含一个可由模型判断的关系。
5. 假设全文统一编号，第4章逐条回应。
6. 画理论模型图，区分直接关系、中介路径和调节位置。
- 配图 1 幅（理论模型图）。

### 第3章 研究设计

任务：交代数据、变量和模型，使读者能按本章复现结果。

3.1 数据来源与样本选择
1. 写分析单位和研究范围，例如"2012—2022 年沪深 A 股上市公司"或"30 个省份"。
2. 写数据来源，列数据库或统计年鉴名称。
3. 按顺序写筛选步骤：剔除金融类、剔除 ST、剔除关键变量缺失等，每步写剔除数量。
4. 写最终样本：企业数、年份数和观测总数，面板数据区分截面单位数与观测数。
5. 写数据处理：缩尾、插值、价格平减，给出变量和处理范围。
6. 匹配多来源数据时，写匹配键和匹配后的样本量。
- 配表 1 张（样本筛选表）；步骤简单时在正文交代。

3.2 变量定义与测量
1. 按被解释变量、核心解释变量、机制或调节变量、控制变量的顺序写。
2. 每个变量写名称、符号、计算方法、单位和数据来源。
3. 被解释变量和核心解释变量写选择理由，引用已有研究的做法。
4. 控制变量依据理论和已有文献选择，每个用一句说明它可能影响什么。
5. 自建综合指数时，写指标体系（维度、指标、属性）、标准化方法和赋权方法（熵值法、主成分法等），给出计算公式。
- 配表 1 张（变量定义表）；自建指数时加 1 张指标体系表。

3.3 模型设定与分析方法
1. 写基准模型方程，式后逐个解释符号，写明关注的系数对应哪条假设。
2. 写估计方法和选择理由，例如 Hausman 检验结果支持固定效应模型。
3. 写固定效应和标准误口径，例如控制个体和年份固定效应、聚类到企业层面。
4. 写机制检验或调节检验的模型，说明新增的变量和交互项。
5. 写本文针对哪些内生性来源（遗漏变量、反向因果、测量误差）准备了哪些处理办法。
- 配公式 2–5 个。

### 第4章 实证结果与分析

任务：报告估计结果，逐条判定假设，检查结果是否可靠，并解释结果的含义。本章表格最多。

4.1 描述性统计与相关分析
1. 给描述统计表：观测数、均值、标准差、最小值、最大值。
2. 挑两到三个有助于理解后文的特征写，例如核心变量的分布差异、样本内的变化幅度。
3. 给相关系数表，说明核心变量之间的初步关联方向。
4. 写多重共线性诊断，给出 VIF 最大值。
- 配表 2 张（描述统计表、相关系数表），可合为 1 张。

4.2 基准回归结果
1. 先用一句说明表中各列的区别，例如第 1 列不加控制变量，第 2 列加入控制变量，第 3 列加入固定效应。
2. 报告核心系数的方向、大小和显著性水平。
3. 按变量单位解释经济含义，例如"解释变量每提高 1 个标准差，被解释变量提高 x%"。
4. 判定 H1 是否得到支持。
5. 只挑理论相关的控制变量简要解释。
- 配表 1 张（基准回归结果表）。

4.3 稳健性检验与内生性处理
1. 每项检验写改动了什么、为什么这样改，例如替换被解释变量的测量方式、缩短样本区间、剔除直辖市。
2. 给结果表，与基准回归使用可比的行列，标出样本量变化。
3. 写核心系数的方向和显著性是否保持。
4. 内生性处理写所用方法（工具变量、滞后一期、倾向得分匹配、双重差分）。
5. 用工具变量时，写工具变量的选择理由、第一阶段结果和弱工具变量检验值。
6. 用双重差分时，写处理组与对照组的划分、政策时点和平行趋势检验。
- 配表 1–2 张；双重差分加 1 幅平行趋势图。

4.4 异质性与机制分析
1. 异质性：写分组依据和各组样本量，给分组回归表，用组间系数差异检验判断差异是否显著。
2. 机制：写所用方法。中介效应按逐步回归或 Bootstrap 写，分别报告总效应、直接效应和间接效应；渠道检验写成"解释变量影响机制变量"的相关证据。
3. 调节效应：写交互项系数，保留各组成项，可配一幅简单斜率图。
4. 门槛或空间模型：写门槛值及区间，或写空间权重矩阵、莫兰指数和直接、间接效应分解。
5. 每项结果判定对应的 H2、H3。
- 配表 1–2 张，配图 0–1 幅。异质性和机制并列时，用三级小节分开。

4.5 结果讨论
1. 按研究问题归并主要发现。
2. 每项发现与第2章文献对照，写相同之处和不同之处。
3. 结合样本特征和理论解释差异。
4. 对未得到支持的假设，先说明检查了计分和模型设定，再给出可能的解释。
5. 段末写本章回答了哪些子问题，作为第5章的依据。

### 第5章 结论、建议与展望

任务：回答绪论的子问题，把结论转成建议，说明研究范围的局限。

5.1 研究结论
1. 用一段交代研究对象、数据和方法。
2. 按子问题顺序列三到五条结论，编号书写。
3. 每条先写发现，给出关键系数或比例，再写适用条件。
4. 逐条回应全部假设，包括未得到支持的。

5.2 对策建议
1. 按行动主体分条写，例如政府、企业、行业协会，三到四条。
2. 每条写依据哪项结论、针对哪类对象、采取什么措施。
3. 异质性结论对应分类施策的建议。
4. 建议的力度与结论的证据强度相当。

5.3 研究局限与展望
1. 从样本范围、测量口径、研究方法三方面写两到三项局限。
2. 每项写它会影响哪部分结论的推广。
3. 每项局限对应一个后续方向，例如扩展到非上市企业、用微观调查数据补充测量、采用准实验设计。

### 问卷变体的写法

第3章 研究设计与数据收集
1. 问卷设计与量表来源：每个量表写来源文献、维度、题数、反向题和计分方式（如 Likert 5 级），说明高分含义；改编的题项写改编理由。
2. 预调查与正式调查：写调查对象、抽样方式、发放渠道和时间，写发放数、回收数、有效问卷数和有效率，写无效问卷的剔除标准（作答时间过短、规律作答、漏答）。预调查写样本量和据此删改的题项。
3. 分析方法：写所用软件（SPSS、AMOS、Mplus 或 PROCESS 宏）和对应检验，写 Bootstrap 抽样次数和置信区间口径。
4. 写匿名作答和知情同意的安排。
- 配表 2 张（量表构成表、样本基本特征表），完整问卷放附录。

第4章 实证结果与分析
1. 样本特征：列性别、年龄、学历等人口学分布；需要时做组间差异检验（t 检验、方差分析）。
2. 信效度检验：报告各量表的 Cronbach's α；验证性因子分析报告拟合指标（χ²/df、CFI、TLI、RMSEA）、因子载荷、AVE 和 CR；区分效度用 AVE 平方根与相关系数比较。
3. 共同方法偏差：写程序控制措施，再报告 Harman 单因子检验的首因子方差解释率。
4. 相关分析：给均值、标准差和相关系数合表。
5. 主效应：用回归或结构方程报告路径系数，判定 H1。
6. 中介效应：用 Bootstrap 报告间接效应值和 95% 置信区间，区间不含 0 判定中介成立，再写直接效应判断完全或部分中介。
7. 调节效应：报告交互项系数，给出调节变量高低两组（均值±1 个标准差）的简单斜率图；有调节的中介报告条件间接效应和判定指标。
8. 结果讨论：独立成节，逐条讨论假设检验结果与已有研究的异同。
- 横截面问卷写"关联""预测"，与问卷设计的时间顺序一致。

## 摘要写法

中文摘要 400–600 字，关键词 4–5 个。

句子功能序列（6–8 句）：
1. 背景与问题：研究对象的现实处境和中心问题，1–2 句。
2. 数据与方法：分析单位、样本范围、样本量和主要模型，1–2 句。
3. 主要结果：按正文顺序写两到四项发现，写方向、关键系数或比例和适用条件，2–3 句。
4. 稳健性或扩展：最重要的一项稳健性、异质性或机制结论，1 句。
5. 结论与启示：基于结果的判断或建议，1 句。

问卷变体在第2项写有效样本量和量表类型，第3项分开写主效应、中介效应和调节效应。摘要的数值、方向和变量名与正文一致。英文摘要与中文逐句对应。

## 质量要点

下面各条是高质量论文里也常出的问题，写作和自查时逐条核对。

1. 同一个数字全文保持一致。样本量、样本区间、有效问卷数、有效率、核心系数、显著性水平和中介效应占比，在摘要、正文、表格和结论中用同一个值和同一精度。
2. 样本筛选每一步的剔除数量相加后与最终样本量吻合；面板数据的观测数等于截面单位数乘以年份数，非平衡面板写明。换样本、缩短区间、剔除部分样本后，结果表标出新的样本量。
3. 结果按完成状态写，样本量、系数、显著性和假设判定前后一致。正文说"显著为正"时，表中系数为正且带对应星号。
4. 每个变量在全文使用同一名称、符号和测量方向。变量定义表、模型方程、回归表和解释段中的变量一一对应。
5. 每条假设在第4章有对应的检验和明确判定，结论章逐条回应，包括未得到支持的假设。理论模型图中的每条路径都有检验结果。
6. 回归表注明被解释变量、括号内数值含义、星号对应的显著性水平、控制变量、固定效应、聚类口径和样本量。
7. 诊断检验的判定方向写对：Hausman 检验拒绝原假设支持固定效应；工具变量第一阶段 F 值大于 10 排除弱工具；AR(2) 不显著才支持 GMM 设定；平行趋势检验中政策前系数不显著。
8. 节名与实际方法一致。中介、调节、门槛、空间溢出、渠道检验各用其实际名称；只回归了机制变量的写"渠道检验"，不写"中介效应"。
9. 组间差异用组间系数差异检验判断，不以"一组显著、一组不显著"直接下结论。
10. 调节效应模型保留交互项的各组成项，交互项变量先中心化，并说明调节方向。
11. 中介效应分别报告总效应、直接效应和间接效应；Bootstrap 写明抽样次数和置信区间，区间与判定一致。
12. 系数的经济含义按变量单位换算：对数变量写百分比变化，比例变量写百分点变化，标准化变量写标准差变化。百分比和百分点分开写。
13. 问卷的维度数、题数、反向题号和计分方向在量表表格、正文和附录问卷中一致；α、AVE、CR 和拟合指标与判定阈值对照写。
14. 横截面数据和问卷数据的结论写"关联""预测"；因果表述只用于有对应识别设计的结论。
15. 建议逐条对应 5.1 的某项结论，力度与证据强度相当。
16. 图、表、公式按章连续编号，正文引用编号与题注一致；合并或删除表格后同步修改全文引用。
17. 绪论的研究内容、技术路线图和论文结构与实际章节一致，研究内容的每一项在后文都有对应章节。
