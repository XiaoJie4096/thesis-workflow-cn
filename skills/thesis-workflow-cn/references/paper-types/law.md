# 法学研究 写作模板

## 适用范围

判断依据：论文以一个法律问题为中心，主要成果是对规范含义、适用条件、权利义务、责任分配、权力边界或制度安排给出有法律根据的回答。正文按"对象与规范→争点→解释或论证→规则回应"展开。判断时看结论靠什么证据成立：需要解释法条、比较学说、分析裁判理由或论证法律效果的，归本类；主要用管理指标找组织问题并提出一般改进对策的，归"案例分析对策研究"；主要检验变量关系、法律只作背景的，归"实证研究"。论文用到访谈、统计或典型案例时，类型按这些材料最终服务的问题来定。

包含的子类：
- 刑法规制：犯罪成立、刑事责任、罪名适用、刑法介入边界。
- 民商法与制度释论：权利义务、请求权基础、合同与侵权责任、商事规则。
- 行政法与新兴领域法律规制：行政权限、行政程序、监管机制，以及数据、平台、人工智能等领域的规制。
- 国际法：条约适用、国际组织规则、国际争端中的法律问题。
- 其他：法理上的理论证成、法律运行的经验机制研究。

本科规模：选题收窄到一个主要法律关系、一个适用阶段和两到三个相互关联的争点，例如一类行为的成立条件、一项权利的救济路径、一套机制的权限边界。题目中的对象在正文中能界定清楚，所研究的规范能找到原文，争点能落到具体的解释分歧或制度后果。

主骨架按"问题诊断与制度完善"写，适合以规范缺口、程序失灵、权限配置或规制方案为主要问题的论文。以法条解释为主的论文按变体 B 写。

## 章节骨架

"必有"的章节每篇都写，"常见"的章节按题目取舍。一项内容可以独立成章，也可以作为某章的一节。

主骨架（6 章，可合并为 5 章）：

第1章 绪论（必有）
- 1.1 研究背景与问题提出（必有）
- 1.2 国内外研究现状（必有）
- 1.3 研究内容、思路与方法（必有，结构安排写在本节末尾）

第2章 基本概念与规范基础（必有）
- 2.1 核心概念界定（必有）
- 2.2 规范依据与法律关系（必有）
- 2.3 理论基础与评价标准（常见）

第3章 现状与核心问题（必有）
- 3.1 现行规范与实践现状（必有）
- 3.2 存在的主要问题（必有）
  - 3.2.1–3.2.3 两到三个核心争点，一个争点一小节
- 3.3 问题成因分析（常见）

第4章 解释选择与方案论证（常见）
- 4.1 竞争方案与分歧所在（常见）
- 4.2 方案论证（本章设立时必有；按题目选规范解释、正当性论证或模式选择中的一种）
- 4.3 域外经验与借鉴（常见）

第5章 制度完善路径（必有；纯释论题目改名为"规则适用与法律效果"）
- 5.1 完善思路与基本原则（常见）
- 5.2 具体完善建议（必有）
  - 5.2.1–5.2.3 与 3.2 的争点一一对应
- 5.3 配套机制与救济衔接（常见）

第6章 结论（必有；可写成未编号的"结语"，不设二级节）

合计 15 个二级节，加一章结论。3.2 和 5.2 是全文最长的两节，各分三个三级小节；其他节不设三级小节。

合并为 5 章的两种做法：
- 不设第4章。竞争方案和取舍理由写进 3.2 各争点小节的末尾，域外经验写进 5.1。
- 第2章并入第1章之后的"概念与规范基础"一章，同时保留第4章。适合概念简单、争议集中在方案取舍的题目。

### 变体

变体 A：问题诊断与制度完善
主骨架即可。行政法、新兴领域规制和刑法改革型题目多用这一结构。

变体 B：规范解释与制度释论
适合以条文解释、请求权基础、构成要件或法律效果为主要问题的题目，民商法题目多用。
- 第1章 绪论（同主骨架）
- 第2章 概念与规则基础（同主骨架）
- 第3章 争点一的规范解释：3.1 问题与观点分歧；3.2 解释论证；3.3 适用与法律效果
- 第4章 争点二的规范解释：4.1 问题与观点分歧；4.2 解释论证；4.3 适用与法律效果
- 第5章 结论
- 现状和问题材料放进各争点章的首节。每个争点章自带结论和适用条件，全文末尾不再另设"完善建议"章。
- 权利或责任型题目，争点章按"法律关系→成立要件→抗辩或排除事由→证明→法律效果"展开，只写决定答案的环节；程序型题目按"启动→运行→衔接→救济"展开。

变体 C：刑法规制
- 改革型：第3章先写刑法介入的必要性和边界，第4章写体系位置与罪名设置，第5章写具体规则。结论可以是限制介入、维持现行规定或通过解释解决。
- 解释型：按变体 B 写，争点章围绕构成要件、违法阻却或责任判断组织。
- 两种写法都用同一个判断标准检验各类情形，解释受罪刑法定原则约束。

变体 D：行政法与新兴领域规制
- 第3章和第5章用同一种划分标准：按权能、按流程阶段或按主体分工，选一种贯穿两章，3.2 的每个问题在 5.2 有对应回应。
- 新兴领域的题目先把技术现象落到一个具体的法律冲突上：权限来源、义务内容、程序保障、责任归属或救济途径。
- 域外比较嵌在 3.2 或 5.1 内部，一般不单独成章。

变体 E：国际法
- 第2章写对象的法律地位和适用的规范层级：条约、国际组织文件、国家实践、国内规定分开写。
- 第3、4章按条约适用问题分章，或用一项原则统摄几个实体议题，每章处理一个议题。
- 第5章写对我国的应对或参与路径，区分国际义务和国内立法选择。

变体 F：理论证成或经验机制
- 理论证成型：第3、4章用两套理论标准检验同一个对象，第5章说明两套标准的结论如何互补，并据此划定制度边界。
- 经验机制型：第3章描述实际运行过程（材料来源、流程、主体互动），第4章做规范评价，第5章把运行证据和规范要求对接，提出边界或调整方案。

## 字数分配

按正文 12000 字分配。本科压缩背景和理论介绍，把篇幅给核心问题、规范论证和规则回应。

| 章 | 占比 | 参考字数 | 浮动范围 |
|---|---|---|---|
| 第1章 绪论 | 15% | 1800 | 1500–2100 |
| 第2章 基本概念与规范基础 | 15% | 1800 | 1500–2200 |
| 第3章 现状与核心问题 | 25% | 3000 | 2500–3400 |
| 第4章 解释选择与方案论证 | 19% | 2280 | 1900–2700 |
| 第5章 制度完善路径 | 23% | 2760 | 2300–3100 |
| 第6章 结论 | 3% | 360 | 300–500 |

节内参考：
- 第1、2章每节约 600 字。
- 第3章：3.1 约 700 字，3.2 约 1600 字（每个争点约 530 字），3.3 约 700 字。
- 第4章：4.1 约 600 字，4.2 约 1080 字，4.3 约 600 字。
- 第5章：5.1 约 600 字，5.2 约 1500 字（每条建议约 500 字），5.3 约 660 字。

合并章的换算：
- 不设第4章时，2280 字分给第3章（约 +1100）和第5章（约 +1180）。
- 变体 B：绪论 1800、概念与规则基础 1800、两个争点章各约 4020、结论 360。争点难度不同时按难度分配，不必两章等长。

篇幅调整：
- 10000 字：用不设第4章的 5 章结构，2.3 并入 2.2，共 11 个二级节。参考分配为绪论 1800、概念与规范基础 1300、现状与核心问题 3200、制度完善路径 3400、结论 300。
- 15000 字：各章乘 1.25，3.2 和 5.2 可各增加一个争点或一条建议。
- 篇幅偏短时先压背景和理论介绍，保留争点分析和规则回应。

## 各章写法

### 第1章 绪论

任务：把现实议题转换成一个可回答的法律问题，说明已有研究的分歧，交代本文怎样回答。

1.1 研究背景与问题提出
1. 用一项规范变化、一类实践分歧或一个典型冲突交代背景，给一到两个可核查的事实或数字。
2. 写现有规则在什么情形下不能直接给出答案。
3. 用一段话区分三层：发生了什么事实，法律上的分歧在哪里，本文回答哪一部分。
4. 写研究意义，落到具体收益：澄清哪个概念、理顺哪处规范关系、改进哪个程序。理论意义和实践意义各写一两句。
5. 材料各有分工：统计数据说明问题范围，个案展示规则适用中的张力，政策文件说明制度语境。

1.2 国内外研究现状
1. 按争点组织，把已有观点分成两到三组。
2. 每组写共同结论、主要依据和不足。
3. 国内外可在同一争点下对比，也可先分述再归并。
4. 用作者和文献作出处，段落主题用法律问题命名。
5. 最后一段写研究述评：本文接受哪些观点，在哪一点上推进。
6. 引用集中在本节。

1.3 研究内容、思路与方法
1. 写主问题，再拆成两到三个分问题，每个分问题对应后文一章。
2. 写研究思路：从概念与规范出发，经争点分析和方案论证，到规则回应。可配一幅研究思路图。
3. 方法只列正文实际用到的，每种写清用法：
   - 规范分析法：解释哪些规范，用文义、体系、目的中的哪些路径；
   - 比较研究法：比较哪些制度，比较哪些维度；
   - 案例分析法：案例从哪里来、时间范围、用来说明什么；
   - 实证调查：材料如何获得，能回答什么问题。
4. 方法动机写成"这个问题需要哪类证据，所以采用这种方法"。
5. 末段写结构安排，每章一句，写清该章任务和前后衔接。
- 配图 0–1 幅（研究思路图）。

### 第2章 基本概念与规范基础

任务：建立后文共用的概念、规范依据和评价标准。

2.1 核心概念界定
1. 从法律文本、学说和实践用法中提炼工作定义，说明为什么这个定义适合本文问题。
2. 列出纳入和排除的范围。
3. 辨析一到两个最易混淆的相邻概念，写清区别以及它影响后文哪项判断。
4. 涉及权利、权能、资格、请求、责任或程序时，分别表述，名称接近也分开用。
5. 需要分类时只用一个主标准，后文沿用这一分类。
- 可配 1 张概念辨析表（比较维度、规范基础、成立条件、法律效果）。

2.2 规范依据与法律关系
1. 先列直接适用的规范，写名称、条号和功能。
2. 再补上位依据、司法解释、部门规章和相关规则。
3. 写清各规范约束谁、处理哪个阶段、冲突时适用哪一条以及理由。
4. 按子类补充：
   - 民商法：写请求权基础和规则之间的关系；
   - 行政法：写权限来源和行使条件；
   - 刑法：写罪名的体系位置和限制条件；
   - 国际法：条约、国际组织文件、国家实践、国内规定分开写。
5. 法条引用现行有效文本，写明法律名称、条号和施行时间；讨论历史文本时注明版本。
- 可配 1 张规范梳理表（规范名称、条款、调整对象、主要内容）。

2.3 理论基础与评价标准
1. 选一到两个后文实际使用的理论，例如比例原则、利益衡量、权力制约理论、风险社会理论。
2. 每个理论写核心主张，再改写成判断条件：检验什么，满足什么才算成立，冲突时如何排序。
3. 写明这一标准在后文哪个问题上使用。
4. 第3–5章回指同一标准。

### 第3章 现状与核心问题

任务：把规范、案例和数据整理成两到三个可争论的法律争点。

3.1 现行规范与实践现状
1. 选一种顺序展开：规范层次、运行阶段或法律主体。
2. 先写现有规范怎样安排，给出条款和功能。
3. 再写实际怎样运行，用案例、数据或调研材料。
4. 最后指出规范安排与实际运行之间的差距。
5. 用案例时写与争点有关的事实、裁判理由和结果，写明案号或来源。
6. 用数据时写来源、统计对象、时间范围和统计口径。
- 可配 1 张规范或案例梳理表，或 1 幅趋势图。

3.2 存在的主要问题
每个争点一个三级小节（3.2.1–3.2.3），按同一顺序写：
1. 现有规则如何处理。
2. 在哪类情形下产生分歧，用一个典型案例或一组材料展示。
3. 列出对立观点，每方写最有力的依据。
4. 指出分歧来源：定义、规范来源、价值排序还是事实认定。
5. 写不同处理造成的法律后果。
6. 归纳问题性质：规定缺失、规定冲突、解释不清、执行偏差或证明困难。性质不同，第5章的回应也不同。
7. 一句话写本文需要判断什么。
- 可配 1 张问题归纳表（争点、典型材料、现有处理、法律后果）。

3.3 问题成因分析
1. 围绕问题的发生机制写原因，每个原因对应 3.2 的一个或几个问题。
2. 规范衔接不明时，写衔接断在哪个环节。
3. 主体职责失衡时，写职责和程序怎样导致这一结果。
4. 技术或社会条件变化时，写原有规则的哪个前提失效。
5. 成因按 3.1 选定的同一顺序排列，便于第5章逐项回应。
- 经验机制类题目可配 1 幅运行流程图，正文解释关键节点和异常情形。

### 第4章 解释选择与方案论证

任务：在竞争方案中作出选择，并给出法律根据和成立条件。

4.1 竞争方案与分歧所在
1. 针对 3.2 的核心争点，列两到三个可行方案或解释。
2. 每个方案写主张、依据和各自产生的后果。
3. 指出方案之间的分歧落在哪个判断点上。
- 可配 1 张方案对照表，各方案用相同栏目。

4.2 方案论证
按题目选一种论证方式：
- 规范解释型：
  1. 确定待解释的用语或适用命题。
  2. 依次从文义、体系位置、规范目的展开，必要时加立法沿革。
  3. 写各解释分别解决什么、带来什么后果。
  4. 采用类推、参照适用或扩张解释时，写法律依据、相似性、差异和限制。刑法题目先核对罪刑法定的边界。
- 正当性论证型：
  1. 先确认法律授权和规范限制。
  2. 写现有替代手段能否解决问题。
  3. 比较所选方案的收益、代价和对权利的影响。
  4. 用第2章的评价标准逐项检验。
- 模式选择型：
  1. 从第3章的问题中提出统一评价维度，例如义务是否明确、裁量是否适度、程序参与和救济是否衔接。
  2. 按这些维度比较两三个模式。
  3. 写选择哪个模式、为什么排除其他模式、结论在什么条件下成立。
  4. 治理效果和法律授权分开评价。
- 写完用一个反例或边界情形检验结论。
- 节末写清答案、成立条件和留给第5章的问题。

4.3 域外经验与借鉴
1. 选一到两个比较对象，说明选择理由，例如问题相似、制度成熟。
2. 按相同维度梳理其规则、适用条件和运行背景。
3. 区分外国现行法、判例、学者主张和改革建议。
4. 写可以借鉴的具体机制，以及在我国适用需要的条件。
5. 比较材料不足以单列一节时，嵌入 3.2 或 5.1。
- 可配 1 张域外制度比较表。

### 第5章 制度完善路径

任务：针对第3章的问题，逐项提出有法律根据、可执行的回应。

5.1 完善思路与基本原则
1. 用一段话说明完善的总体思路，对应第4章的论证结论。
2. 列两到三项基本原则，每项写含义和它约束哪些具体建议。
3. 先写现行法框架内能解决的部分，再写需要修改规则的部分。

5.2 具体完善建议
每条建议一个三级小节（5.2.1–5.2.3），与 3.2 的争点一一对应，按同一顺序写：
1. 回应哪个问题。
2. 规范根据：依据哪条现行规定，或建议修改哪一条。
3. 适用对象和启动条件。
4. 具体内容：主体职责、行为规则或程序步骤。
5. 例外情形和法律后果。
6. 与既有制度的衔接。
- 建议写到可操作的程度，写明谁在什么条件下做什么。
- 结论可以是解释澄清、程序细化、限制介入或维持现行规则，只要回应了问题并给出理由。
- 可配 1 张问题与对策对应表，或 1 幅职责分工图。

5.3 配套机制与救济衔接
1. 写实施建议需要的配套条件：资源、信息、程序或授权。
2. 写不符合条件时的转入路径和救济渠道。
3. 用一个边界情形检验整套方案：是否覆盖第3章的问题，是否制造新的冲突，是否为例外情形留出救济。
- 多主体协同或多阶段衔接时可配 1 幅流程图。

变体 B 的争点章：每章按"问题与观点分歧→解释论证→适用与法律效果"写，首节写该争点的现状材料和分歧，末节写成立条件、法律效果和适用界限。

### 第6章 结论

1. 用一两句概括本文完成的核心判断。
2. 按主要问题分条写结论，两到三条，每条写对象、答案和成立范围。
3. 结论只归纳正文已经论证的判断，与摘要的核心结论一致。
4. 用一两句写研究局限：材料覆盖范围、解释范围或尚待判断的条件。
5. 篇幅约 360 字，复杂题目可到 500 字。

## 图表配置

法学论文以文字论证为主，图表按内容需要配置。全文图 0–2 幅、表 0–3 张，参考文献 20–30 篇，外文占 20%–40%。纯规范释论的论文可以不配图表。

| 位置 | 类型 | 配置条件 |
|---|---|---|
| 1.3 | 研究思路图 | 章节之间的推进关系需要直观展示 |
| 2.1 | 概念辨析表 | 两个以上相邻概念需要按同一维度比较 |
| 2.2 | 规范梳理表 | 相关规范较多、层级不同 |
| 3.1 | 案例梳理表或趋势图 | 有一组可比案例或可靠的年度数据 |
| 3.2 | 问题归纳表 | 争点较多，需要集中对照 |
| 3.3 | 运行流程图 | 经验机制类题目，有多个实际节点 |
| 4.1 / 4.3 | 方案对照表、域外制度比较表 | 两个以上方案或制度按同一维度比较 |
| 5.2 / 5.3 | 问题与对策对应表、职责分工图或程序流程图 | 多主体协同或多阶段衔接 |

- 表格和图后面接着写论证：从中读出什么，支持哪项判断。
- 图表有编号、题注和来源；涉及数据时写明单位和时间范围。
- 图表编号按章编排（图 3-1、表 5-1），正文先引用、后出图表。
- 公式只在比例规则、条件判断等确有必要时使用，先定义符号，再解释法律含义。
- 参考文献区分来源性质：法律法规、司法解释、裁判文书、政策文件、学术文献分别标注，出处紧跟被支持的判断。

## 摘要写法

中文摘要 300–450 字，关键词 3–5 个，用正文中稳定使用的术语。

句子功能序列（6–8 句）：
1. 背景与问题：哪种规范关系出现了什么争议，1–2 句。
2. 对象与范围：本文研究的对象和讨论范围，1 句。
3. 方法：实际使用的分析方法和材料，1 句。
4. 主要分析与结论：两到三个核心判断及其依据，2–3 句。
5. 回应或意义：提出的规则回应，或结论的适用范围与制度用途，1 句。

按变体调整：
- 制度完善型：写查明了哪些规则问题、选定哪种回应及理由、回应如何衔接。
- 规范释论型：写对哪些争点形成什么解释结论、成立条件和法律效果。
- 经验机制型：写材料范围、观察到的运行过程，以及据此提出的规范边界。
- 国际法：写适用的规范层级或条约问题。

字数紧张时压背景和一般意义，保留核心结论。摘要写研究内容和答案，按问题和结论组织句子。摘要和结论共享核心结论，措辞各自写。英文摘要与中文逐句对应。

## 质量要点

下面各条是高质量论文里也常出的问题，写作和自查时逐条核对。

1. 绪论提出的每个分问题，在第3–5章都有对应的分析和回应；结论只归纳正文已论证的判断。
2. 3.2 的每个争点在 5.2 都有一条对应建议，编号和顺序一致。
3. 绪论的结构安排、章首说明和实际目录一致。正文中"前文第……章""下文第……节"的互引在调整章节后重新核对。
4. 引导句宣布的项目数与实际列出的项目数一致，例如"三个方面"后面列三项。
5. 同一概念全文用同一名称，首次出现时定义；译名、简称、作者姓名拼写前后一致。
6. 同一分类标准贯穿全文。第3章按主体划分时，第5章也按主体回应；换用阶段划分时写明理由。
7. 构成要件、评价标准、模型的项数和方向在前后章节一致，结论中的编号与正文对应。
8. 每处法条引用写明法律名称、条号，使用现行有效文本；涉及修订、废止或过渡适用时，写明版本和事实发生时适用的文本。
9. 法律条文、司法解释、政策文件、学说观点和裁判理由分别标明性质，各按其效力层级使用。
10. 案例写明案名或案号、审理法院和裁判时间，叙述的事实和裁判结果与出处一致。
11. 同一数字在摘要、正文、表格中保持一致，写明来源、统计对象和时间范围；总量、分量和比例的口径一致。
12. 每项判断先给法律根据再下结论。评价方案效果前，先确认法律授权和限制条件。
13. 结论的强度与材料对应：几个典型案例支持"存在这类情形"，系统的数据才支持比例和趋势判断。
14. 每条完善建议写明规范根据、适用对象、启动条件、具体内容和法律后果，每条都写到谁在什么条件下做什么。
15. 区分现行法下的解释结论和立法建议，立法建议写明修改哪一规定、如何与既有制度衔接。
16. 比较材料区分外国现行法、判例、学者主张和改革建议，借鉴部分写明在我国适用的条件。
17. 图表题注、正文称谓和交叉引用一致，图和表分开编号。
18. 摘要、正文和结论的核心结论一致，摘要中的关键词在正文中稳定使用。
