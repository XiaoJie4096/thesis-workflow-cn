# 设计创作策划方案 写作模板

## 适用范围

判断依据：论文的主要成果是作者完成的原创设计方案、创作成果或教学方案，正文按"对象与问题 → 设计依据 → 调研与需求 → 设计策略 → 设计实践 → 方案评价"展开，核心是能回查的设计决策和完整成果。如果论文只研究某种设计现象或评价已有环境，没有原创方案，按主要研究任务归"实证研究"或"案例分析对策研究"类；如果主要成果是可运行的软件系统，归"系统设计与实现"类。

包含的子类：
- 品牌与视觉传达设计：成果是视觉识别系统、传播应用和品牌接触点。
- 文创与产品设计：成果是文化转译后的产品系列及其使用方式。
- 景观与环境设计：成果是有场地边界、空间关系和尺度的环境方案。教育空间设计归这一类。
- 教学设计：成果是依据课标和学情编制的目标、任务、活动和评价，以及教学实施效果。

本科规模：围绕一个明确对象做一套可交付的方案。设计类写 2–4 项单品、接触点或节点；教学类写一个完整单元或一个课例（2–4 课时）。资源介绍只作依据，篇幅留给需求到成果的推导。

## 章节骨架

"必有"的章节每篇都写，"常见"的章节按题目取舍。主骨架 6 章、17 个二级节，按品牌、产品、景观的通用流程写；教学设计的差异写在变体 D。每个二级节不少于 600 字。三级小节只在并列展示几项单品、几个场地节点或几个课时时使用，每个不少于 400 字。

第1章 绪论（必有）
- 1.1 研究背景与意义（必有）
- 1.2 国内外研究现状（必有）
- 1.3 研究内容与方法（必有；含研究路线图和论文结构）

第2章 相关理论与设计依据（必有）
- 2.1 核心概念界定（必有）
- 2.2 理论基础与设计资源（必有；文化类题目写资源要素）
- 2.3 理论对本设计的指导（必有；输出"依据—要求"对照）

第3章 现状调研与设计需求（必有）
- 3.1 设计对象现状分析（必有）
- 3.2 用户调研与分析（必有；问卷、访谈或观察）
- 3.3 同类设计案例分析（常见；可并入 4.2）
- 3.4 设计问题与需求归纳（必有）

第4章 设计定位与设计策略（必有）
- 4.1 设计定位与目标（必有）
- 4.2 设计原则与方法（必有）
- 4.3 总体构思与方案推演（必有）

第5章 设计实践与方案评价（必有）
- 5.1 设计要素提取与转译（必有）
- 5.2 设计方案展示（必有；按单品、接触点或节点分 5.2.1–5.2.3）
- 5.3 应用场景展示（常见）
- 5.4 方案评价与优化（必有）

第6章 总结与展望（必有）
- 不分二级节，按"研究总结""不足与展望"两部分写。

每章末设"本章小结"（必有），用 3–4 句写在最后一节末尾，不单列节号；绪论和总结章可不设。

合并为 5 章的做法：调研资料较少时，第2章与第3章合为"设计依据与需求分析"，保留 2.1、2.2、3.2、3.4 四节，其余章顺移。

### 子类变体

变体 A：品牌与视觉传达设计
2.2 写品牌文化或地域资源的含义、视觉特征和应用约束；3.1 写现有识别、传播渠道和接触点；5.2 按"基础识别系统（标志、标准色、标准字、辅助图形）→ 应用系统 → 传播与衍生品"分三级小节；5.3 写线上线下接触点的应用效果。

变体 B：文创与产品设计
2.2 写文化资源的提取路径；3.2 常用问卷加访谈，3.4 可用 KANO 等模型给需求排序；5.1 写"文化元素—形态—功能—材质"的转译；5.2 按产品系列分三级小节，每件写功能、结构、尺寸、材质和使用流程；5.4 用用户问卷评价。

变体 C：景观与环境设计
3.1 写区位、边界、自然与人文条件、功能流线和使用现状，配场地分析图；第4章按"问题位置—人群活动—功能分区—流线—节点"推演；5.2 先给总平面，再按场地分区或节点分三级小节；5.3 写分析图、断面和季节或时段场景；5.4 可用专家打分或使用者满意度评价。

变体 D：教学设计
- 第2章 写学习理论和教学模式，2.3 把理论命题转成目标、情境、支架或评价要求。
- 第3章 改为"课标教材与学情分析"：3.1 课程标准与教材分析、3.2 学情调查与分析、3.3 教学问题与设计需求。
- 第4章 改为"教学设计思路与模式建构"：4.1 教学目标设计、4.2 教学模式与流程、4.3 学习评价设计。
- 第5章 改为"教学案例设计与实施"：5.1 单元整体规划、5.2 课时教学设计（按课时分三级小节）、5.3 教学实施过程、5.4 教学效果评价与反思。

## 字数分配

按正文 12000 字分配。压缩重复理论和先例介绍，篇幅给需求推导和设计实践。

| 章 | 占比 | 参考字数 | 浮动范围 |
|---|---|---|---|
| 第1章 绪论 | 15% | 1800 | 1500–2250 |
| 第2章 相关理论与设计依据 | 15% | 1800 | 1500–2250 |
| 第3章 现状调研与设计需求 | 20% | 2400 | 2000–3000 |
| 第4章 设计定位与设计策略 | 18% | 2150 | 1800–2700 |
| 第5章 设计实践与方案评价 | 27% | 3250 | 2700–4050 |
| 第6章 总结与展望 | 5% | 600 | 500–750 |

- 第5章内部：5.1 约 650 字，5.2 约 1300 字（三个三级小节各约 430 字），5.3 约 600 字，5.4 约 700 字。
- 不写 3.3 时，600 字分给 3.2 和 4.2；不写 5.3 时，600 字并入 5.2。
- 合为 5 章时，合并章约 3000 字，省下的 1200 字分给第4章和第5章。
- 变体 D 参考：绪论 1800、理论 1800、课标教材与学情 2000、教学设计思路 2000、教学案例设计与实施 3800（单元规划 650、课时设计 1500、实施过程 800、效果评价与反思 850）、总结 600。

## 各章写法

### 第1章 绪论

任务：说明对象的现实问题，已有研究做到哪里，本文设计什么、按什么路线做。

1.1 研究背景与意义
1. 写清研究对象、服务人群和使用或教学情境。
2. 交代政策、文化、行业或课程变化，给一到两个数字或事实。
3. 写对象当前的具体不足，例如识别混乱、产品同质、场地闲置、课堂任务碎片化。
4. 把背景收束到设计能回应的问题。
5. 写理论意义和实践意义，各一到两句，落到具体使用者。

1.2 国内外研究现状
1. 按两条主题线组织：一条写研究对象，一条写所用设计理念或方法。教学类按"教学内容"和"教学模式"分线。
2. 每条线内先国外后国内，每项写"谁、研究了什么、提出什么做法、得到什么成果"。
3. 每条线末尾写一两句述评：已有成果、仍受什么条件限制。
4. 最后一段把缺口写具体，例如对象覆盖、转译过程、任务链或评价方式的缺失，并对上本文工作。
5. 引用集中在本节。
- 可配 1 张文献比较表（研究对象、方法、成果、局限）。

1.3 研究内容与方法
1. 把总问题拆成 2–3 个研究问题：对象需要什么，依据怎样转成方案，形成了什么成果。
2. 研究内容按问题顺序列 3–4 项，每项写"针对什么、做什么、产出什么"。
3. 研究方法写文献研究、问卷与访谈、案例分析、设计实践、评价方法，每种写用途和材料来源。
4. 画研究路线图，标出各阶段的输入和输出。
5. 每章一句写论文结构。
- 配图 1 幅（研究路线图）。

### 第2章 相关理论与设计依据

任务：给出后文真正使用的概念、理论和资源，并转成设计要求。

2.1 核心概念界定
1. 从文献或规范给出定义，比较相近概念的适用范围。
2. 给出本文的操作性界定：对象、目标、主要机制、边界。
3. 尽早固定对象口径：品牌接触点范围、产品使用情境、场地边界和尺度、课程学段和教材范围。后文保持同一口径。

2.2 理论基础与设计资源
1. 只选后文会用到的 2–3 项理论。
2. 每项理论按"核心观点 → 与本对象的适配性 → 将改变哪些设计动作"写。
3. 文化类题目写设计资源：来源和含义 → 形态、色彩或行为特征 → 可转译要素。
4. 资源要素分为直接保留、抽象提炼、重新组合三类。
- 配图 1–2 幅（资源要素图或理论框架图）。

2.3 理论对本设计的指导
1. 逐项把理论或资源转成设计要求：品牌转成色彩、形态、字体和叙事要求；产品转成功能、结构、材质和使用方式要求；景观转成可观察的空间要素和尺度。
2. 采用既有框架时，写清原框架的要素，再写本题保留、删减或增加的部分及理由。
3. 列"依据—设计要求"对照表，作为第4章策略的坐标。
4. 本章小结：列出后文使用的要素和约束。
- 配表 1 张（依据与设计要求对照表）。

### 第3章 现状调研与设计需求

任务：通过调研得出问题清单和需求，作为设计和评价的依据。

3.1 设计对象现状分析
1. 写对象范围、当前构成和使用条件。
2. 品牌写现有识别、传播渠道和接触点；产品写目标人群、使用场景和市场现有产品；景观写区位、边界、自然人文条件、流线和使用现状。
3. 先列事实，再给判断，每项判断后接一句设计含义。
- 配图 1–2 幅（现状照片、场地分析图或现有产品图）。

3.2 用户调研与分析
1. 写调研设计：对象选择、时间地点、方法（问卷、访谈、观察）、问卷维度。
2. 写发放与回收：发放份数、有效份数、有效率。本科问卷常取 100–300 份，访谈 5–10 人。
3. 按需求维度报告结果，不按题号逐题解释。每张结果表后写关键差异和设计含义。
4. 比例写清分母和多选口径。
5. 访谈按主题归并代表性意见，受访者用编号（如 A1、A2），写出归纳依据。
6. 需要区分需求优先级时，用 KANO 模型或层次分析法，给出计算结果并转成"优先响应、保留、暂缓"三类措施。
- 配表 1–2 张（受访者基本信息表、调研结果表），配图 1 幅（结果统计图）。

3.3 同类设计案例分析
1. 选 2–3 个案例，写清可比条件：对象类型、规模、受众相近。
2. 固定比较维度，例如定位、元素提取、表现手法、应用范围。
3. 逐例写可借鉴的做法和不宜直接移用的条件。
4. 末尾一段回到本对象，列出借鉴点。
- 配图 1–2 幅（案例图，注明来源），可配 1 张案例比较表。

3.4 设计问题与需求归纳
1. 把现状、调研和案例的结论归为 3–5 个设计问题。
2. 每个问题按"证据（出自哪一节）→ 解释 → 设计需求"写。
3. 需求编号（如 R1–R5），第4章策略和 5.4 评价都回指这些编号。
4. 需求冲突时写权衡：优先满足谁，在什么情境下兼顾另一方。
5. 本章小结：用一句话列出需求编号和名称。
- 配表 1 张（问题—证据—需求对照表）。

### 第4章 设计定位与设计策略

任务：把需求转成目标、原则和方法，推演出总体方案。

4.1 设计定位与目标
1. 由需求确定服务对象、使用情境和设计定位，可写成一句定位语。
2. 目标写成能在图面、产品或场地中检查的表现，每条对应需求编号。
3. 写限制条件：既有空间、媒介、使用条件、预算、材料和工艺。

4.2 设计原则与方法
1. 提出 3–4 条有区分度的原则，每条写对应问题、理论依据和行动要求。
2. 写设计方法或流程，按阶段写输入、动作、输出，前一阶段的成果是后一阶段的依据。
3. 品牌从定位和核心语义生成视觉语言和接触点要求；产品从文化提取和需求确定功能、形态、结构和使用过程；景观从问题位置和人群活动推出分区、流线、节点。
4. 每项策略写清为什么出现、与其他策略怎样共同解决问题。
- 配图 1 幅（设计流程图或策略框架图），配表 1 张（需求—原则—策略对照表）。

4.3 总体构思与方案推演
1. 写总体构思：设计主题、核心概念、整体结构。
2. 提出 2–3 个备选方向，配草图。
3. 按第3章需求逐项比较，写保留、修改、放弃的理由。
4. 确定最终方案，说明它在哪些需求上更好。
5. 本章小结：写最终构思和第5章要完成的具体成果。
- 配图 2–3 幅（构思图、草图推演、总体结构图）。

### 第5章 设计实践与方案评价

任务：展示完整设计成果，并用评价证明成果回应了需求。

5.1 设计要素提取与转译
1. 按"原始资源 → 提取 → 简化或重构 → 设计元素"写转译过程。
2. 每一步写提取了什么、改变了什么、为什么这样改。
3. 建立可回查的关系：文化含义与视觉形式、功能与结构、活动与空间。
4. 第4章已解释的原则只点名，不重复理论。
- 配图 2 幅（元素提取图、转译过程图）。

5.2 设计方案展示
1. 先给成果总览，再按单品、接触点或节点分三级小节。
2. 每个三级小节按同一顺序写：设计说明 → 对应需求编号 → 关键尺寸、色彩或材质 → 效果图。
3. 品牌：标志及释义、标准色和标准字、辅助图形、应用规范；检查字体、色彩、比例在各应用中一致。
4. 产品：系列关系、功能和使用流程、主要构件、尺寸、材质工艺；写清是效果图、样机还是实物。
5. 景观：总平面、功能分区、道路与流线、各节点；节点写使用人群、位置、尺度、材料和植物。断面、分析图和效果图互相对应。
- 每个三级小节配图 1–2 幅（效果图、样机照片、平面或节点图，正文保留图号，图片由用户补入）。

5.3 应用场景展示
1. 选 2–3 个典型使用情境，写成果在其中怎样被看到、被使用。
2. 品牌写线上线下接触点；产品写使用场景和包装陈列；景观写不同季节、时段的活动场景。
3. 每个场景写对应的需求编号。
- 配图 2–3 幅（场景效果图）。

5.4 方案评价与优化
1. 写评价方法：用户满意度问卷、专家打分或可用性测试，选一到两种。
2. 评价指标由第3章需求编号转来，一项需求对应一到两个题项。
3. 写评价对象和过程：人数、身份、评价时间、展示方式。问卷常取 50–100 份，专家 5–10 人。
4. 列评价结果表，按指标给均值或得分率。
5. 用同一组指标对照第3章需求逐项说明达成情况。
6. 写得分较低的指标，给出修改措施，展示修改前后对比。
7. 本章小结：写成果组成、评价结论和优化内容。
- 配表 1–2 张（评价指标表、评价结果表），配图 1 幅（结果统计图或优化前后对比图）。

### 第6章 总结与展望

1. 研究总结：按绪论的研究问题逐条回答，3–4 条。每条写依据、完成的成果和关键数据，与摘要一致。
2. 区分调研发现、提出的方法、交付的方案和评价结果，各用一条写。
3. 不足与展望：写研究范围的局限，例如调研地域和人群范围、设计媒介、实现深度、评价周期。
4. 每条局限接一项可执行的后续工作，例如扩大调研范围、制作实物样机、开展长期使用跟踪。

### 变体 D 教学设计的写法

3.1 课程标准与教材分析
1. 写课标对本学段本内容的要求。
2. 写教材单元结构、各课之间的联系、核心知识点。
3. 列"课标要求—教材内容—教学重点"对照表。

3.2 学情调查与分析
1. 用问卷或访谈调查学生已有知识、兴趣、学习困难，写清对象班级、人数、时间。
2. 结合教师访谈或课堂观察，写现有教学的问题。
3. 按维度报告结果，每项结果接一句教学含义。

3.3 教学问题与设计需求
1. 把课标、教材和学情的结论归为 3–4 个教学问题。
2. 每个问题转成编号需求，后文目标、任务和评价都回指这些编号。

4.1 教学目标设计：按内容和认知层次写单元目标和课时目标，每条可观察、可评价。
4.2 教学模式与流程：比较已有模式的共性，写本文增补的环节和理由，画流程图；写核心任务和子任务的递进关系。
4.3 学习评价设计：先定什么成果能证明目标达成，再写评价指标和表现等级，配评价量规表。

5.1 单元整体规划：写课时总量、各课时任务和成果去向，配课时安排表。
5.2 课时教学设计：每课时一个三级小节，用"教学环节—教师活动—学生活动—设计意图—对应目标"表写，重点活动展开问题和支架。
5.3 教学实施过程
1. 写实施班级、人数、执教教师、周期和课时。
2. 按课时写实际过程和学生产出，配课堂照片和学生作品图。
3. 写实施中的调整和原因。
5.4 教学效果评价与反思
1. 写评价工具：前后测、实验班与对照班、课后问卷或量规评分。
2. 列结果表，前后测或两班对比给均值和差值，必要时给 t 检验结果。
3. 按维度对照第3章需求和第4章目标说明效果。
4. 反思目标任务匹配、课时负担、支架和评价的可操作性，写修改方向。

## 摘要写法

中文摘要 350–500 字，关键词 3–5 个。

句子功能序列（6–8 句）：
1. 背景与问题：对象所处情境和具体不足，1–2 句。
2. 对象与目标：本文以……为对象，设计了什么，1 句。
3. 依据与方法：用了什么理论，做了什么调研，1 句。
4. 关键设计动作：需求怎样转成视觉、功能、空间或教学任务，1–2 句。
5. 成果与评价：形成了什么成果，评价结果给一到两个关键数字，1 句。
6. 意义：成果可为……提供参考，1 句。

- 品牌和产品突出需求到视觉或功能的转译；景观突出问题到空间措施的对应；教学突出教学模式、完整课例和实施效果。
- 摘要中的人数、方案数量、流程名称和评价数值与正文一致。
- 英文摘要与中文逐句对应。

## 质量要点

下面各条是写作和自查时逐条核对的检查项。

1. 同一对象在题目、摘要、章名、图题和结论中用同一名称，范围、阶段数、方案数和单品数一致。
2. 调研数字全文一致：发放份数、有效份数、各项比例、评价人数和得分在正文、表格、摘要和结论中用同一个值和同一精度。
3. 比例由表中数据算出，写清分母和多选口径。百分点和百分比分开写。
4. 第3章需求编号在第4章策略、第5章成果和 5.4 评价中都能找到对应。每项需求至少对应一项设计动作和一个评价指标。
5. 评价指标逐项回扣第3章需求，结果表的指标名称和正文一致。
6. 每个设计元素写出来源和转译理由，形式变化说明为什么选它。
7. 设计成果按实际形态称呼：效果图、样机、实物、施工图分别写清。
8. 图表编号连续不重复，正文先引用后出现，题注与图表内容一致。外部案例图注明来源，与作者方案分开。
9. 景观平面和断面有比例、方向和单位，节点尺寸和总平面一致。
10. 品牌各应用中的标准色色值、字体和标志比例与基础规范一致。
11. 教学目标、任务、评价在同一张对照表里对齐，各课时的环节名称与教学流程图一致。
12. 教学效果数据写清对象、人数、周期和工具，前后测人数一致。
13. 绪论的研究内容和论文结构与实际章节一致，研究问题在结论中逐条有回答。
14. 理论只写后文用到的内容，第2章出现的每项理论在第4或第5章有落点。
