# 算法模型改进 写作模板

## 适用范围

判断依据：论文的核心贡献是“在一个已有算法或模型上做 1–3 处改进，并用实验证明改进有效”。题目常见“基于改进……的……研究”“……算法的改进及其应用”。如果核心贡献是搭建一个完整系统（需求、数据库、界面、测试用例），归入系统设计与实现类；如果核心是设备或结构的设计计算，归入工程设计类。

这一类有两条并列主线，先判断题目属于哪一条，再按对应主线写第 3、4 章：

- 主线 A：深度学习模型改进。原有网络（基线）→ 在骨干、颈部、注意力、损失函数等位置做改进 → 在数据集上做消融实验和对比实验。适用子类：目标检测、图像分类或分割、时序预测（深度模型）、自然语言处理、推荐系统。
- 主线 B：群智能/启发式优化算法改进。原算法（粒子群、麻雀、鲸鱼、灰狼、遗传、蚁群、A* 等）→ 改进策略（初始化、自适应参数、变异扰动、混合其他算法）→ 基准测试函数或标准算例实验 → 工程应用（路径规划、调度、选址、参数辨识、特征选择等）。适用子类：路径规划或优化，以及“用改进优化算法去优化某个模型参数”的题目。

还有一类“经典算法改进”（卡尔曼滤波、K-means 聚类、决策树、滑模观测器、控制律），写法是方法章按主线 B 写（原理 → 缺陷 → 改进公式 → 流程），实验章按主线 A 写（数据或工况 → 指标 → 对比曲线和误差表）。

## 章节骨架

本科版写 5 章，每章 3–5 个二级节。硕士论文多出的第二个方法章或工程应用章，本科并入第 3、4 章。

### 共用部分

第 1 章 绪论（必有）

- 1.1 研究背景及意义（必有）
- 1.2 国内外研究现状（必有）
- 1.3 主要研究内容（必有）
- 1.4 论文组织结构（常见，可与 1.3 合并）

第 2 章 相关理论与技术（必有）

- 主线 A：2.1 深度学习/卷积神经网络基础（必有）；2.2 任务相关算法的发展与分类（必有）；2.3 基线模型原理（必有，可放在第 3 章首节）；2.4 本章小结。
- 主线 B：2.1 原算法的仿生原理与数学模型（必有）；2.2 原算法流程（必有）；2.3 原算法存在的问题（常见）；2.4 问题数学模型或环境模型（有具体应用对象时写）；2.5 本章小结。

第 5 章 总结与展望（必有）

- 5.1 工作总结（必有）
- 5.2 研究展望（必有）

每章末“本章小结”（必有），总结与展望章除外。

### 主线 A：深度学习模型改进

第 3 章 基于改进……的……方法（必有）

- 3.1 基线模型分析与改进思路（必有）
- 3.2 改进点一（必有）
- 3.3 改进点二（必有）
- 3.4 改进后的整体模型结构（常见）
- 3.5 本章小结

第 4 章 实验结果与分析（必有，独立成章）

- 4.1 实验环境与参数设置（必有）
- 4.2 数据集（必有；自建数据时写采集、筛选、增强、标注）
- 4.3 评价指标（必有）
- 4.4 消融实验（必有）
- 4.5 对比实验（必有）
- 4.6 可视化结果分析（必有；可加训练曲线）
- 4.7 本章小结

### 主线 B：群智能/启发式优化算法改进

第 3 章 改进……算法设计（必有）

- 3.1 改进策略一（必有）
- 3.2 改进策略二（必有）
- 3.3 改进算法流程与伪代码（必有）
- 3.4 本章小结

第 4 章 实验结果与分析（必有）

- 4.1 实验设置：测试函数或标准算例、对比算法、参数（必有）
- 4.2 性能测试结果与分析（必有）
- 4.3 收敛曲线分析（常见）
- 4.4 参数或策略有效性分析（常见）
- 4.5 工程应用（常见；路径规划、调度、选址等应用题目必写）
- 4.6 本章小结

### 子类变体

- 目标检测：第 2 章写“两阶段/单阶段检测算法演进”，基线多为 YOLO 系列；指标用 P、R、mAP@0.5、mAP@0.5:0.95，可加参数量、GFLOPs、FPS。
- 图像分割：第 2 章加“语义/实例分割任务对比”；指标用 Dice、IoU，可加边界距离；可视化写“原图/标签/基线/改进”四列。
- 图像分类：指标用准确率、精确率、召回率、F1，加混淆矩阵（补充）。
- 时序预测：第 4 章加“样本构造”一节（滑动窗口、归一化、按时间顺序划分训练/测试）；指标用 MAE、RMSE、MAPE、R²。
- 自然语言处理、推荐系统：按主线 A 骨架写，指标按任务选择（补充）。
- 路径规划：第 2 章加“环境建模”（栅格法或三维地形 + 威胁区）；第 4 章应用节用 2–3 张不同复杂度地图，指标为路径长度、转折次数或转角、迭代次数、运行时间；可加路径平滑。
- 调度、选址、车辆路径等组合优化：第 2 章写“问题描述 → 模型假设 → 符号 → 目标函数 → 约束”；第 4 章用标准算例（如 Solomon、TSPLIB）或构造算例代替测试函数。
- 改进优化算法去优化模型参数（如优化 BP 网络权值、优化分类器超参数、多阈值分割）：第 3 章末加一节“参数编码与适应度设计”，写清个体维数和适应度函数；第 4 章先做函数测试，再做模型应用对比。
- 经典算法改进（滤波、聚类、控制）：第 2 章写对象模型或算法原理；第 4 章按“同一工况/数据下基线与改进对比 → 误差统计表 → 改变工况或参数检验鲁棒性”写。

## 字数分配

按正文 12000 字分配：

| 章 | 占比 | 参考字数 | 浮动范围 |
|---|---:|---:|---:|
| 第 1 章 绪论 | 20% | 2400 | 2100–2800 |
| 第 2 章 相关理论与技术 | 20% | 2400 | 1900–2900 |
| 第 3 章 改进方法 | 25% | 3000 | 2500–3600 |
| 第 4 章 实验结果与分析 | 30% | 3600 | 3000–4200 |
| 第 5 章 总结与展望 | 5% | 600 | 450–700 |

主线差异：

- 主线 A 理论章篇幅较多，可取 2600–2900 字，第 3 章相应减到 2600 字左右。
- 主线 B 有问题建模时，建模内容（假设、目标函数、约束）放在第 2 章，第 2 章取 2600–2900 字；没有具体应用对象时，第 2 章取 1900–2200 字，把省下的字数给第 4 章的测试结果分析。
- 第 4 章内部：实验设置和数据/算例约 25%，主要结果（消融+对比或函数测试）约 45%，可视化或应用约 30%（补充）。

## 各章写法

### 第 1 章 绪论

任务：说明为什么要改进这个算法，现有方法做到了哪一步、还差什么，本文改了哪几处。

1.1 研究背景及意义

1. 写应用领域的需求，可用 1–2 个行业数据或政策说明规模。
2. 写人工方式或传统方法的局限。
3. 收束到具体技术难点。主线 A 写任务难点（如小目标、遮挡、背景复杂、资源受限）；主线 B 写优化问题的复杂性（非线性、多约束、高维）和传统精确方法的局限。
4. 引出所选基线或原算法，写它的优点，再写它的不足。
5. 一句话写研究意义（理论意义 + 应用价值）。

1.2 国内外研究现状

1. 按技术路线或改进策略分类组织，各类分别成段或成三级节。主线 A 常用“传统方法 → 深度学习两阶段 → 单阶段 → 本任务专项方法”；主线 B 常用“初始化改进、参数自适应、更新策略改进、混合算法”，或按方法族“搜索类、采样类、智能类”。按方法分类比按国内、国外分段更常见。
2. 每类先说思路，再列 2–4 篇代表文献，写“改了什么 → 效果如何 → 还有什么不足”。
3. 应用对象明确时加一条应用线，写该领域已有的求解或检测研究。
4. 最后一段归纳研究缺口，并与本文改进点一一对应。
5. 全文过半引用集中在本节，本节引用 15–20 篇。

1.3 主要研究内容

1. 先一句话写总体思路：以……为基线，针对……问题进行改进。
2. 逐条列改进点，每条写“针对的问题 + 采用的方法 + 预期作用”。本科写 2 个改进点，最多 3 个。
3. 写验证方式：用什么数据集或测试函数，与什么方法对比。
4. 可配一幅研究内容框架图或技术路线图。

1.4 论文组织结构：每章一句，写这一章承担什么任务，体现“理论准备 → 改进方法 → 实验验证 → 总结”的递进。

### 第 2 章 相关理论与技术

任务：给出后文要用到的概念、公式和基线原理，为“改哪里”做铺垫。

主线 A：

1. 2.1 写卷积神经网络基础：卷积、池化、激活函数、损失函数，每项“作用 + 公式或示意图”。只写后文用得到的部分。
2. 2.2 写任务相关算法的发展：按两阶段/单阶段或按版本演进，比较结构差异，最后说明选择基线的理由（精度、速度、模型规模）。
3. 2.3 写基线模型原理：先给整体结构图，再按输入端、骨干、颈部、检测头（或编码器、解码器）、损失函数逐部分讲，标出后文要修改的位置。
4. 改进中要用到的模块（注意力、特征融合结构等）的原理，可以放在本章，也可以放在第 3 章对应节。
5. 配图 6–8 幅（结构图、模块示意图），公式 5–8 个。

主线 B：

1. 2.1 写原算法的启发来源（自然行为）和角色划分。
2. 2.2 写数学模型：定义种群、个体位置、适应度；分阶段写位置更新公式，逐项解释参数的含义和取值范围。
3. 2.3 写算法步骤（分条列出）和流程图。
4. 2.4 写原算法存在的问题：结合公式说明哪一步会导致早熟、收敛慢或探索开发不平衡。能用一张散点图或一个简单推导说明更好。
5. 有具体应用时加 2.5 问题建模：问题描述 → 模型假设（逐条）→ 符号说明表 → 决策变量 → 目标函数 → 约束条件（逐式解释）。多目标用加权合成时，写明权重取值和量纲归一化方法。
6. 配图 2–4 幅，公式 8–15 个，表 1–2 张（符号表、参数表）。

### 第 3 章 改进方法（主线 A）

任务：把每个改进点讲成“为什么改 → 改成什么 → 放在哪里”，让读者能对照结构图复现网络。

3.1 基线模型分析与改进思路

1. 简述基线在本任务上的具体不足（如下采样丢失小目标细节、背景干扰、感受野固定、定位损失收敛慢、参数量大）。
2. 每个不足对应一个改进点，给出总体改进结构图，在图上标出改动位置。

3.2、3.3 每个改进点一节，按四步写：

1. 动机：从上一节指出的不足出发，说明原结构为什么做不好。
2. 原理：介绍所采用模块的计算过程，配模块结构图和公式（如注意力权重计算、损失函数表达式）。注明模块出处，写“引入”“借鉴”，把本文的改动和原模块区分开。
3. 位置：说明插入或替换在网络的哪一层，以及为什么放在这里。
4. 结果结构：给出加入本改进后的网络结构图（局部或阶段图）。

常见改进类型，按常用程度排列：注意力模块、特征融合或颈部结构、骨干替换或轻量化、卷积模块替换、损失函数、增加检测头。本科选 2 个，最好分布在不同位置（如一个改特征提取、一个改损失）。

3.4 改进后的整体模型结构：给出最终整体结构图，可附逐层参数表（层名、输入输出尺寸、参数），说明各改进在整网中的位置。

3.5 本章小结：按改进点逐条回收“解决什么问题、怎么改的”。

配图 6–10 幅（每个改进点 2–4 幅），表 0–2 张，公式 4–8 个。

### 第 3 章 改进方法（主线 B）

任务：给出每个改进策略的公式和作用，最后合成可执行的改进算法。

3.1、3.2 每个改进策略一节，按四步写：

1. 缺陷：指出原算法哪一步造成什么问题（如随机初始化分布不均、固定参数难兼顾前后期、只跟随最优个体导致早熟、后期停滞）。
2. 策略：给出改进公式，逐项解释符号。
3. 图示：画参数随迭代变化的曲线、混沌序列分布图或策略示意图。
4. 作用：说明对全局探索和局部开发的影响，即前期怎样、后期怎样。

常见策略，按常用程度排列：自适应参数或非线性权重、变异或扰动（Levy 飞行、柯西、高斯、差分变异）、混合其他算法（模拟退火、差分进化、局部搜索等）、混沌映射初始化、反向学习。路径规划还常改启发函数、信息素更新、节点删除和路径平滑。本科选 2–3 个策略。

3.3 改进算法流程与伪代码

1. 分条写完整步骤，标明新增步骤的位置。
2. 画流程图，改动部分用不同颜色或虚线框标出。
3. 写伪代码。
4. 可加时间复杂度分析：先写原算法复杂度，再写新增步骤带来的增量。

有具体应用时加 3.4 参数编码与适应度设计：写清一个个体代表什么（如一条路径的若干航点坐标、一组网络权值、一个特征子集的 0/1 向量），维数是多少，适应度怎样由第 2 章的目标函数计算，约束怎样处理（罚函数或修复）。

配图 3–5 幅，公式 6–12 个，伪代码 1 段。

### 第 4 章 实验结果与分析（主线 A）

任务：在统一条件下证明每个改进有效、整体优于其他方法。

4.1 实验环境与参数设置

1. 一张环境配置表：CPU、GPU、内存、操作系统、深度学习框架及版本。
2. 一张训练参数表：输入尺寸、batch size、epoch、优化器、初始学习率、学习率策略、是否用预训练权重。
3. 写明所有对比模型都在同一环境、同一参数下训练。

4.2 数据集

1. 公开数据集：写名称、来源、类别、图像数量、划分方式和比例。
2. 自建数据集：按“采集来源与数量 → 筛选 → 数据增强（方法与扩充后数量）→ 标注工具与规则 → 划分比例”写。
3. 用 1 幅样例图和 1 幅类别分布或目标尺寸统计图说明数据难点。
4. 训练集、验证集、测试集的数量写全，三者相加等于总数。

4.3 评价指标：先定义 TP、FP、FN（可用混淆矩阵表），再给各指标公式，说明数值越大还是越小越好。轻量化题目加参数量、GFLOPs、FPS，并说明 FPS 的测试硬件。

4.4 消融实验

1. 一张表，每行一种配置，用“√”标出加入了哪些改进，列出各项指标。
2. 2 个改进点时写 4 行：基线、基线+改进一、基线+改进二、完整模型。这是全组合，能分别看出单项和组合的贡献。3 个改进点时至少写“基线、逐个单加、完整”5 行。
3. 逐行分析指标变化，单位用“个百分点”表述绝对差；某项指标下降时如实写出并解释原因。

4.5 对比实验：选 3–5 个主流模型（包括基线），在同一数据集、同一环境下训练测试，一张表列出指标；可加 P-R 曲线。写清对比模型的结果是自己复现的还是引自文献。

4.6 可视化结果分析

1. 训练曲线：损失曲线、mAP（或准确率）随 epoch 变化曲线，说明收敛情况。
2. 效果对比图：选 3–4 组典型场景（漏检、误检、遮挡、小目标），按“原图 / 基线 / 改进模型”排列，逐组说明差异。
3. 可加热力图或混淆矩阵。

4.7 本章小结：回收消融和对比的主要数值。

配表 4–6 张，图 5–8 幅。

### 第 4 章 实验结果与分析（主线 B）

任务：先用基准测试证明改进算法的寻优性能，再用工程应用证明它能解决实际问题。

4.1 实验设置

1. 测试函数表：名称、表达式、维数、搜索范围、理论最优值，分单峰和多峰。本科选 8–12 个经典函数，维数取 30。
2. 对比算法：原算法 + 3–5 个其他算法（如 PSO、GWO、WOA、SSA 或近年改进版）。
3. 参数表：各算法的参数取值及来源。
4. 统一种群规模、最大迭代次数和独立运行次数（常取 30 次）；写软硬件环境。

4.2 性能测试结果与分析

1. 一张结果表，列每个函数上各算法的最优值、平均值、标准差，可加平均排名。
2. 先分析单峰函数（反映收敛精度和速度），再分析多峰函数（反映跳出局部最优的能力）。
3. 改进算法在某些函数上不占优时，如实写出并分析原因。
4. 可加 Wilcoxon 秩和检验，显著性水平取 0.05（补充）。

4.3 收敛曲线分析：选 4–6 个代表函数画平均收敛曲线（纵轴取对数），对比收敛速度和最终精度。

4.4 策略有效性分析：构造“原算法、只加策略一、只加策略二、完整改进”4 个版本，在部分函数上比较，说明各策略的作用。参数需要选定时，固定其他参数、逐个改变一个参数，用表格或曲线选折中值。

4.5 工程应用

## 质量要点

下面各条是高质量论文里也常出的问题，写作和自查时逐条核对。

1. 正文、摘要、结论里的每个数字都与表格一致。写提升幅度时先从表中两个数直接相减，绝对差写“提高了……个百分点”，相对增幅写“提高了……%”，两种说法分开使用。
2. 结论只概括表格支持的内容。改进方法在某些函数、某些类别或某些指标上不是最优时，在正文中写出来并解释原因，总结里用“在……个函数上”“在大多数指标上”这样的限定说法。
3. 数据集的总数、各子集数量和划分比例三者对得上，训练集、验证集、测试集各写一个数字；用测试集选参数时如实说明，最好单独留出验证集。
4. 每个结论都有对应的实验数据。写“速度基本不变”“可部署到移动端”“实时”时，给出在对应硬件上测得的 FPS 或耗时；没有测，就把它放到展望里。
5. 对比实验和消融实验分开命名：同一基线不同模块组合叫消融，与其他方法比较叫对比。对比方法的结果注明是自己在同一环境下复现，还是引自文献。
6. 消融表能支持你对每个改进点的结论。逐个累加的消融只能说明“在前一配置基础上加入……后的变化”，要说明单个模块的独立贡献，就做“基线 + 单个模块”的对照。
7. 图号、表号、公式号按章连续编号，不重号、不跳号；正文引用的图表号与题注一致；题注写出图表的实际内容。
8. 公式、伪代码、文字描述三者一致：同一个参数的名称、取值、更新方向在三处相同；最大化还是最小化在目标函数和选择操作中保持一致。
9. 单位和指标名称准确：FPS 是帧/秒，模型大小用 MB，参数量用 M；表头写的是 F1 就称 F1，写的是标准差就不称方差。
10. 迭代次数和运行时间分开报告。说“收敛更快”时指明是按迭代次数还是按实际耗时；改进增加了计算步骤时报告运行时间。
11. 加权合成的单目标优化称为“加权单目标”，求出帕累托前沿才称多目标优化。
12. 借鉴的模块（注意力、损失函数、混沌映射、Levy 飞行等）写明出处，用“引入”“借鉴”描述，并在文中把本文的修改部分单独说明。
13. 仿真结果写“仿真结果表明”，不写成实际系统或实物上的效果；展望里写清还缺哪些实物或真实数据验证。
14. 参考文献编号连续，正文引用与文末条目一一对应，同一文献只列一次。
