# 人文论述 写作模板

## 适用范围

判断依据：论文以原始文本、史料或思想命题为主要证据，通过细读、考订、比较和论证回答一个解释问题。研究结果是对意义、历史过程、概念关系或解释分歧的判断，并写明判断成立的条件。以问卷和统计检验回答变量关系的，归实证研究类；以法律规范的效力与适用为核心的，归"法学"；以方案或作品交付为核心的，归设计或策划类。题目涉及社会或教育问题时，同样按主要证据和论证方式归类。

包含的子类：
- 文学：作家、作品、作品群、文类、断代或地域文学现象。
- 历史：制度史、社会史、交通与历史地理、档案文书、艺术史。
- 哲学/思想：经典文本、核心概念、思想系统、教育哲学。
- 交叉题目按实际使用的证据选写法。

本科规模：对象收窄到一组可核验的文本、一个制度运行环节或一条概念关系。题目、材料范围、章内分析和结论范围用同一口径。论文的贡献可以是校正事实、重释文本、澄清概念、重建论证或解释机制，结论落在学术判断上，政策建议按题目取舍。

## 章节骨架

"必有"的章节每篇都写，"常见"的章节按题目取舍。主骨架 5 章、18 个二级节。

第1章 绪论（必有）
- 1.1 问题的提出（必有）
- 1.2 研究现状与评议（必有）
- 1.3 研究对象、材料与方法（必有，末段交代论证路线）

第2章 <核心概念与背景>（必有；对象背景简单时并入绪论，全文改为四章）
- 2.1 核心概念的取义（必有）
- 2.2 <对象>的形成条件（必有）
- 2.3 材料基础与分析标准（必有）
- 章名写具体对象，例如"'某某'的取义与生成语境""某制度的沿革与史料"。

第3章 <分论点一>（必有）
- 3.1 <判断一>
- 3.2 <判断二>
- 3.3 <判断三>
- 3.4 <判断四>
- 3.5 <异说辨析与本章结论>

第4章 <分论点二>（必有）
- 4.1–4.4 <判断一至四>
- 4.5 <异说辨析与本章结论>

第5章 结语（必有）
- 5.1 主要结论（必有）
- 5.2 研究边界与后续问题（必有）

专题章的写法：
- 第3、4章各回答一个子问题，两章可区分、又前后相接。章名写成观点或具体对象，例如"乡村书写中的'归来者'形象""某县里甲的实际运行"，写出本章的具体对象或主张。
- 节名写成本节要成立的判断或要分析的具体对象。
- 一节要并列分析几部作品、几类史料或几个概念时，设三级小节，每个三级小节至少 400 字。
- 确有第三个独立问题且材料够时，加一个专题章，全文六章。专题章从专题总字数中分配，每章 4 节。

### 子类变体

变体 A：文学
- 专题按问题链推进。常用两种安排：
  - 第3章写"某种经验或形象如何呈现"，第4章写"叙述与语言如何生成这一效果"。
  - 围绕同一问题设几个互补的观察维度，各占一章或一节，最后一节建立维度之间的关系。
- 形式或书写特征章（常见）：节名写叙述视角、时间组织、语言方式、意象关系等分析对象。
- 价值或审美功能（常见）：放在后一个专题章的末节，也可单独成章。
- 按作品分期组织时，先给分期节点的依据，各期比较同一问题。分期和特征是两种方案，选一种，同一材料只在一处详细分析。
- 跨作品研究先整体清点，再选主例。单篇研究围绕关键结构和解释分歧逐层推进。

变体 B：历史
- 专题顺序：事实或运行过程复原（第3章）→ 行动者与制度关系解释（第4章）。对象与史料边界放在第2章，整体判断放在结语。
- 时间是解释条件时，在专题内部交代先后过程。确有阶段比较任务时，各阶段用同一组观察维度。
- 史料复杂时，在第2章设"史料来源与考订"一节。
- 研究范围的说明（必有）：放在绪论 1.3，结语 5.2 再回收。

变体 C：哲学/思想
- 专题顺序：问题前提与概念（第2章）→ 原典论证重建（第3章）→ 关系、争议或适用条件检验（第4章）。
- 价值、启示或现实审视（常见）：作为后一个专题章，或第4章末节。题目不涉及现实应用时，把篇幅给反对意见、逻辑层次和解释比较。
- 交代取义和文本选择的范围，放在 1.3。
- 理论来源和逻辑根据各有任务，选一条能推进问题的主线写。

## 字数分配

按正文 12000 字分配。本科压缩背景和材料规模，篇幅给专题分析。

| 章 | 占比 | 参考字数 | 浮动范围 |
|---|---|---|---|
| 第1章 绪论 | 15% | 1800 | 1500–2100 |
| 第2章 概念与背景 | 15% | 1800 | 1500–2100 |
| 第3章 专题一 | 30% | 3600 | 3000–4200 |
| 第4章 专题二 | 30% | 3600 | 3000–4200 |
| 第5章 结语 | 10% | 1200 | 1200–1500 |

- 各章浮动范围不同时取上限。总字数改为 10000 或 15000 时，按比例缩放，再检查专题章是否仍能展开主例、比较和限定。
- 第2章并入绪论时，绪论增设"核心概念与背景"一节，共 4 节、约 2400 字，其余 1200 字分给两个专题章。
- 设三个专题章时，专题总额 7200 字分为三章，每章约 2400 字、4 节。
- 每节先定要完成的证据任务，再安排段落。两节材料悬殊时，合并弱节或调整子问题。

## 各章写法

### 第1章 绪论

任务：把研究对象转成一个可回答的问题，说明已有研究做到哪一步，交代材料、方法和论证路线。

1.1 问题的提出
1. 指出一个能在材料中定位的现象、解释冲突或事实疑点。
2. 说明它为什么影响对研究对象的认识。
3. 从离问题最近的一层写背景：时间、区域、文体、思想语境或制度条件，说明它们怎样造成分析困难。
4. 把问题写成可回答的形式：要辨清什么关系，现有解释在哪个环节不足，用什么材料检验。
5. 写研究意义，分别落到文本解释、史实认识或概念辨析上。个人经历和时代背景各用一两句带过。

1.2 研究现状与评议
1. 把已有成果按问题、解释路径、材料层级或学派分成 2–3 组。
2. 每组写"谁回答了哪一问题 → 依据什么材料 → 留下哪一具体困难"。
3. 国内外分开写只用于确有不同研究传统和材料条件的题目，分开后仍按问题组织。
4. 区分不足的类型："研究少""材料未用""解释不充分""观点相反"，把本文任务定位到其中一种。
5. 引用某项判断前回到原文核验。
- 全文引用的研究文献集中在本节。

1.3 研究对象、材料与方法
1. 逐项写对象、时空、材料和取义范围。
   - 文学：交代全集、单行本、报刊或总集的底本，纳入和排除标准，跨版本差异的处理原则。
   - 历史：按当时政区、实际控制或联系范围界定空间，写明与今地名的对应；时间断限写起止事件及其与论题的关系。
   - 哲学：写所据原典、译本、作者或合著者范围；选全书还是核心篇章，说明代表性。
2. 把每种方法对应到具体操作和产出：
   - 细读：关注哪些词语、结构或叙述关系；
   - 比较：比较单位、尺度和可比条件；
   - 史料考订：版本互校、时间校核或来源判断；
   - 概念分析：词用、注释、逻辑位置、相邻概念。
3. 用到理论工具时，写来源、核心命题、适用前提，以及它能识别对象中的哪种现象。
4. 写方法可能遮蔽什么，以及用哪类材料约束。
5. 末段写论证路线：各章解决哪个子问题，前后怎样依赖。
- 对象清单较长时配文本范围表或史料来源表 1 张。

### 第2章 概念与背景

任务：建立后文共同使用的概念、条件和标准。

2.1 核心概念的取义
1. 选出全文反复使用、有多义、会改变材料归类的 1–3 个核心概念。
2. 列出有实质差别的几种解释，写各自取义和适用范围。
3. 给出本文的工作定义和识别标准。
4. 历史词语先还原当时含义。现代分析术语写明由研究者采用，并给出它与原文现象的对应依据。
5. 辅助术语在首次使用处说明。
- 可配概念关系图或概念对读表 1 张。

2.2 <对象>的形成条件
1. 从后文问题反推需要哪些条件，只写这些条件。
2. 写作者经历时，给出经历与具体文本变化之间的证据。
3. 写思想来源时，说明命题被吸收、修订还是反驳。
4. 写制度沿革时，把规范变动和实际运行分开写。
5. 写影响关系时，给出接触、传播、引述或共同问题的证据。只有相似时，结论写成比较判断。
6. 概念的形成史和它在论证中的逻辑根据分开写。
- 可配沿革表 1 张。

2.3 材料基础与分析标准
1. 按来源分类：原始作品、原始记录、后出编纂、口述资料、研究文献。
2. 每类写能回答什么问题、可能在哪里失真。
   - 文学：访谈和创作谈呈现作者自述，解释仍用作品检验。
   - 历史：写档案的存藏、整理和残缺，方志注明与事件的时间距离。
   - 哲学：注疏和译本呈现解释传统，注家判断和原作者判断分开。
3. 本章末段把前提转成专题任务，列出后文重复使用的标准。
- 可配版本对照表或史料来源表 1 张。

### 第3、4章 专题章

任务：每章回答一个子问题，用材料分析成立一个分论点，并处理异说和反例。

章首段
1. 写本章问题和分论点。
2. 说明它与上一章结论的关系。

每个判断节，步骤固定：
1. 用一句话写本节要成立的判断。
2. 定位证据：作品段落、档案条目、原典篇章或历史事件，写明版本和页码。
3. 交代理解证据所需的最小语境。
4. 引用直接承担论证的部分。
5. 解释关键词、关系、动作或推理，说明材料怎样支持判断。
6. 用一两个短例扩展主例，篇幅留给主例的深入分析。
7. 引入相近材料、反向材料或已有异说，说明判断在什么条件下成立。
8. 遇到不一致时，区分版本差异、时间差异、主体立场和研究口径。能解决的给出取舍标准，不能解决的保留并限定结论。
9. 节末回答本节问题，说明它怎样推进全章。
10. 同一证据再次使用时，换一个问题来问，并注明见前文某节。

异说辨析与本章结论（每个专题章末节）
1. 集中处理与本章分论点相反的解释，先写出对方最有力的理由。
2. 说明本文接受、修订还是反对，依据是什么。
3. 综合各节判断之间的关系，回答本章问题。
4. 引出下一章要解决的问题。

变体 A：文学专题
1. 研究内容、形象或经验时：
   - 先给分类依据；
   - 选能显示差异的场景或段落，分析人物关系、叙事位置和情境变化；
   - 情节梗概只用于定位，分析落在词语选择、意象连接、视点转移、时间次序和语体效果上。
2. 区分作者、叙述者、人物和研究者的声音。人物言论结合叙述框架和情境理解。文本中相互矛盾的声音作为解释结构的一部分来分析。
3. 研究形式或书写特征时：
   - 先界定分析单位和观察尺度；
   - 叙事视角：写谁看见、谁知道、谁讲述，信息差怎样改变理解；
   - 时间组织：写顺序、速度、重复与作品意义的联系；
   - 语言和意象：写用法的重复、变形、语境和对照；
   - 给形式命名后，接着写它产生什么审美、认知或情感效果。
4. 用词频、分布或分类统计时，交代底本、统计单元、检索标志和排除项，使表中数量能回到作品核查。
5. 比较研究时：先固定问题和比较层次，说明文本为何可比，再分析相同形式承担的不同功能，或同一问题采取的不同表现。
6. 写接受史时，作品的实际特征和后来读者、评论者的解释分开写。
7. 价值判断回收前文细读结果，分别写审美、文化、认识或文献意义及其适用范围。作品的艺术局限另起一段写。
- 可配语料范围表、分类分布表或文本对读表 1 张。

变体 B：历史专题
1. 写史料身份：形成时间与所记事件时间分开，辨明作者、记录者、整理者和后世转述者。
2. 判断互证前检查是否同源。两条说法出自同一底本时，再找独立材料。
3. 对人名、地名、年号、货币和制度用语做必要考订，写取舍依据。用换算结果时写口径、单位和误差来源。
4. 有异说时列清各来源及其计量范围，再写能成立的共同判断。
5. 复原运行过程时，按问题追踪主体、行动、规则、资源和结果。
6. 把制度规定、行政奏报、契约诉状和实际执行分层写，说明谁在什么处境下作记录。当事人的自利陈述与其他材料对照。
7. 由个案讨论一般制度时，先说明个案的典型性和例外性，写明哪些结论只在局部成立。
8. 解释原因时，区分促成条件、直接契机、行动者选择和偶然事件，写出它们在过程中怎样连接。
9. 比较地区或时段时，固定观察维度，确认资料完整程度和统计单位可比。区域材料回应宏观解释时，写明外推范围。
10. 图像、地图和文书格式本身作为材料分析，在正文指出可见细节，说明它们怎样改变判断。
11. 访谈和田野资料注明时间、地点、对象身份。
- 可配史料汇总表、制度对照表、事件沿革表或历史地图 1–2 项。地图上每个定位和路线注明来源。

变体 C：哲学/思想专题
1. 从原典中的问题位置入手：交代句段回应的对象和上下文，澄清术语在该处的含义。
2. 原典没有现代术语时，说明本文依据哪些命题和关系重建这个问题，研究者的概念和作者原话分开标示。
3. 字源和词用作为线索，再用篇章、注解、相邻概念和整体论证检验其哲学含义。
4. 译名有差异时选定一种用法，在影响推论处说明不同译法的后果。
5. 把作者论证拆成前提、推理步骤和结论，标出哪些前提明说、哪些需要重建。补入隐含前提时给出文本依据和其他可能解释。
6. 处理反例时，说明它触及的是概念定义、推理有效性还是适用范围。能修正的重述命题，不能消解的写成限度。
7. 评价思想时，历史作用、概念贡献和论证困难分开写，先分析原论证，再给当代评价。
8. 比较不同传统时，先写共同问题和可比层次，再处理术语不完全对应、理论目标和背景差别。
9. 写理论来源与影响时，给出传承、接触或文本证据。只有相似时，写成比较判断。
10. 写现实启示时，按"已证命题 → 中介条件 → 可适用问题"推进，写明时代、主体、制度和实践条件的变化。条件不足时，结论落在概念澄清、解释修正或理论批判上。
- 可配概念对读表或概念关系图 1 张，图中每个箭头都能回到正文推理。

### 第5章 结语

任务：综合回答绪论提出的总问题，写明结论的范围和后续问题。

5.1 主要结论
1. 开头直接回答总问题。
2. 按发现之间的关系合并两个专题章的结论，写"通过证据成立了什么判断"。
3. 区分已证事实、较可靠的解释和仍需条件的推论。
4. 回到 1.2 中的具体争议，说明本文在哪一层推进了认识。
5. 写价值时只用正文已展开的发现。
   - 文学：落在意义如何生成和文学史位置；
   - 历史：落在运行关系和解释范围；
   - 哲学：落在概念关系、论证贡献和困难。

5.2 研究边界与后续问题
1. 写本研究的边界，落到材料缺失、版本范围、代表性或方法的具体环节，说明它怎样限制结论。
2. 研究对象自身的局限放在专题章评价，这里只写本研究的边界。
3. 由边界推出 2–3 个后续问题，写明还需要哪类材料或哪种比较。

## 图表配置

本类以文字、引文和注释为主，图表少，可以全文无图表。全文图 0–2 幅、表 0–3 张；历史题目材料整理需求较多时，可用表 1–4 张。参考文献 20–35 篇，外文占 20%–40%，兼顾原始文本、代表研究和争议文献。

| 位置 | 类型 |
|---|---|
| 1.3 / 2.3 | 文本范围表、史料来源表、版本对照表 |
| 2.1 | 概念关系图或概念对读表 |
| 2.2 | 沿革表 |
| 专题章（文学） | 文本对读表、分类分布表 |
| 专题章（历史） | 史料汇总表、制度对照表、历史地图 |
| 专题章（哲学） | 概念对读表、论证关系图 |
| 专题章（视觉材料） | 书影、作品局部、文书或地图细节 |

- 只选真正帮助核查和比较的图表，每项在正文中解释读出的结论。
- 图表按首次出现顺序编号，正文先引用再出现。标题写清对象、时点和比较内容，表下注明口径和资料来源。续表沿用原编号，跨章复用时交叉引用。
- 引文对读表的版本、页码与原文一致。地图写明底图和重绘来源。作品图版写作者、作品名和藏处。
- 分布表和频数表写总量、单位、缺失和分类规则。
- 公式只用于史料单位换算、明确定义的指标或原典的形式论证，写明符号含义和适用条件。

## 摘要写法

中文摘要 400–600 字，关键词 3–5 个。正文完成后再写。

句子功能序列：
1. 问题（1–2 句）：对象中尚待解释的现象或分歧，背景只写理解问题所需的部分。
2. 范围与材料（1 句）：文本、时空或概念范围，材料来源。
3. 方法（1 句）：实际执行的比较、释读、考订或论证动作。
4. 核心发现（2–3 句）：用判断句写专题发现及其相互关系。这是摘要的主体。
   - 文学：什么呈现方式产生了什么效果；
   - 历史：过程和主体关系得到怎样的修正；
   - 哲学：概念关系或论证重建得出什么结论。
5. 意义与条件（1 句）：解释意义及其适用条件，写具体贡献。

- 摘要写完成后的结果，与正文的分期名称、概念译名、材料总量和范围一致。
- 关键词选对象、核心问题、关键概念或必要方法。
- 英文摘要与中文逐句对应，人名、作品名和术语译法与正文统一。

## 质量要点

下面各条是高质量论文里也常出的问题，写作和自查时逐条核对。

1. 核心术语、人名、作品题名和译名全文统一。首次出现时写明取义和所用版本，换用含义时标明语境。
2. 摘要、目录、正文和结语使用相同的分期名称、章名和研究范围，阶段数量和章序一致。
3. 每节都有"判断 + 证据 + 分析"。只有材料的节补上判断，只有判断的节回到原文补证据或收缩命题。
4. 作者、人物、叙述者、史料记录者、注家、后学和研究者的判断分别标明归属。
5. 转述他人观点时先完整写出观点和理由，再写本文评价。
6. 直接引文与原文一致，并注明版本和页码；间接转述也能找到出处。同一文本全文用同一底本和页码系统，换版本时注明理由。
7. 结论的范围与证据的范围一致。由单例、局部区域或核心篇章得出的结论，写明推广所需的条件。
8. 篇名、署名、出版年和人物年代经过核对，同名人物、相似地名和后来称谓区分清楚。
9. 历史年号与公元纪年互校，档号、记录日期、事件日期与正文表述一致。
10. 分期节点有事实依据，并且能解释所讨论的变化。
11. 汇总数字在正文、摘要和表格中一致。分项合计等于总数，百分比按同一分母计算，分类有重叠时注明。
12. 图表编号连续唯一，正文引用指向正确的图表，图表内容支撑邻近的判断。
13. 同一材料只在一处详细分析，其他位置交叉引用。
14. 结语写综合后的答案，背景只在绪论出现一次。摘要只写正文已展开的结论。
15. 绪论 1.3 的论证路线与实际章节一致，提出的每个子问题在后文都有对应章节。
16. 研究对象的局限写出证据；本研究的边界落到材料、方法或范围的具体环节。
17. 小节编号连续，层级和题名与目录一致；全文没有占位符、衍字或未改的复制标题。
