# 实验研究 写作模板

## 适用范围

判断依据：论文的主要成果来自一组实验。正文设置处理或比较条件，测定对象的响应，再用结构、组成或分子层面的证据解释差异，回答"有没有作用、作用多大、在什么条件下成立、凭什么解释"。正文按"问题→材料与方法→结果→解释与讨论→结论"展开。若只用公开数据库或问卷数据做统计推断，归"实证研究"类；若核心是软件或软硬件系统的设计、实现和功能测试，归"系统设计与实现"类；若核心是装置或结构的设计计算，归"工程设计"类。实验只起辅助作用时，按主问题选模板。

包含的子类：
- 材料制备与性能：合成、改性、复合材料，测结构与性能。
- 食品与天然产物：加工、贮藏、提取、组分与品质或功能。
- 植物与微生物胁迫机制：胁迫或处理下的表型、生理和分子响应。
- 动物或细胞模型药理机制：受试物或模型的效应与机制线索。
- 环境修复与资源化：吸附、降解、修复材料的效果和影响条件。

本科论文围绕一条主线，用一个主要体系或一组处理完成"对象确认→主要效应→解释证据"的证据链。多体系、多轮筛选、多组学的研究压缩成回答主问题所需的几个环节。

## 章节骨架

"必有"的章节每篇都写，"常见"的章节按题目取舍。节名换成本题的具体对象和指标，例如"3.2 改性程度对吸附容量的影响"，不照搬"主要效应""解释证据"这类通用词。

主骨架（5 章，15 节）：

第1章 绪论（必有）
- 1.1 研究背景与意义（必有）
- 1.2 国内外研究现状（必有）
- 1.3 研究目标、内容与技术路线（必有，含论文结构安排）

第2章 材料与方法（必有）
- 2.1 实验材料与仪器（必有）
- 2.2 实验设计与样品制备（必有；生物类写"实验设计与处理"）
- 2.3 测定指标与数据处理（必有；指标分属两到三类时用三级小节，如 2.3.1 结构表征、2.3.2 性能测定、2.3.3 数据处理与统计分析）

第3章 实验结果与分析（必有）
- 3.1 样品表征或对象状态确认（必有）
- 3.2 处理对核心指标的影响（必有）
- 3.3 因素水平或时间变化的影响（常见；单因素梯度、多因素组合或时间序列）
- 3.4 稳定性、重复使用或验证实验（常见）

第4章 机理分析与讨论（必有；证据少时按合并做法并入第3章）
- 4.1 结构或组成与性能（效应）的关联（必有）
- 4.2 作用机制分析（常见；有表达、谱图变化、组学或模型拟合证据时写）
- 4.3 与已有研究的比较及适用条件（必有）

第5章 结论与展望（必有）
- 5.1 主要结论（必有）
- 5.2 研究局限与展望（必有）

第3、4章不单设"本章小结"节，在最后一节末尾用一段话收束本章判断（必有）。第3章中某节要并列报告几项指标或几组实验时用三级小节，每个小节至少 400 字；一段能说清的内容不拆小节。

合并与拆分：
- 3.3、3.4 都不适用时，把 3.2 按指标类别拆成两节，第3章保持 3 节以上。
- 解释证据较少时，第4章并入第3章，章名改为"实验结果与讨论"，全文 4 章：4.1 与 4.2 合成一节"机理分析"，4.3 保留为"与已有研究的比较"，接在 3.4 之后。第3章最多 5 节，超出时合并 3.3 与 3.4。
- 不设独立文献综述章，综述写在 1.2。

### 变体

变体 A：材料制备与性能
主骨架即可。2.2 写配比、合成或改性路线和样品编号；3.1 写形貌、物相、组成表征（SEM、XRD、FTIR、XPS 等），确认材料按设计形成；3.2 写核心性能；3.3 写改性量、温度等因素的梯度；3.4 写循环稳定性或重复使用。4.1 写结构与性能的对应，4.2 写反应或作用机理（动力学、等温线拟合、自由基捕获等）。做两轮改进时按变体 F 拆章。

变体 B：食品与天然产物
2.1 写原料产地、品种、批次和初始品质；2.2 写加工、贮藏或提取工艺及分组。3.1 写组分或结构基础；3.2 写品质或功能指标；3.3 写工艺参数或贮藏时间的影响，做工艺优化时写单因素加响应面或正交试验，最后做验证试验；3.4 写稳定性或货架期。4.1 把组成、结构与品质联系起来。体外活性、模型功能与人体健康价值分层写。

变体 C：植物与微生物胁迫机制
2.1 写材料（品种、菌株）和培养条件；2.2 写胁迫或处理设计、取样时间点和重复。3.1 确认胁迫或处理已经生效（表型、生长指标）；3.2 写生理生化指标；3.3 写时间序列，分初始、作用和恢复阶段；3.4 写基因表达或含量测定。4.2 用表达、组学或通路线索解释已观察到的效应，结论写成响应规律和参与因素。

变体 D：动物或细胞模型药理机制
2.1 写受试物来源和纯度、动物品系或细胞系、饲养或培养条件、伦理审查说明；2.2 写分组（正常组、模型组、阳性药组、受试物剂量组）、给药方式和周期。3.1 确认造模成功；3.2 写功能或表型指标；3.3 写剂量效应；3.4 写组织病理、表达或通路指标。4.2 写机制线索，区分细胞、动物和人体三个层次。

变体 E：环境修复与资源化
主骨架按变体 A 写。3.2 写去除率或修复效果；3.3 写 pH、投加量、初始浓度、共存离子等条件；3.4 写重复使用和实际水样或土样验证。4.2 区分去除、降解、矿化和稳定化，写二次风险。

变体 F：两项递进实验（按实验拆章）
研究分两个递进环节时，第3章写"实验一"、第4章写"实验二"，每章 3–4 节，先写本章问题，再写结果和章内讨论；第5章改为"综合讨论"（3 节：两项实验的关联、与已有研究的比较、适用条件），第6章为结论与展望。第2章写两项实验共用的材料和方法，各实验特有的条件写在本章首节。第二项实验开头用一段说明第一项实验确定了什么、留下什么问题。

## 字数分配

按正文 12000 字分配，15 节平均约 800 字。绪论和原理介绍压缩，篇幅给结果和解释。

| 章 | 占比 | 参考字数 | 浮动范围 |
|---|---|---|---|
| 第1章 绪论 | 17% | 2000 | 1800–2500 |
| 第2章 材料与方法 | 18% | 2200 | 1800–2700 |
| 第3章 实验结果与分析 | 35% | 4200 | 3500–5200 |
| 第4章 机理分析与讨论 | 20% | 2400 | 1800–3000 |
| 第5章 结论与展望 | 10% | 1200 | 1200–1500 |

- 每个二级节不少于 600 字。某章取到浮动下限、平均每节不足 600 字时，按合并做法减少节数。
- 节内参考：1.1 约 600，1.2 约 800，1.3 约 600；2.1 约 600，2.2 约 700，2.3 约 900；3.1 约 900，3.2 约 1300，3.3 约 1100，3.4 约 900；4.1 约 800，4.2 约 900，4.3 约 700；5.1 约 600，5.2 约 600。
- 第4章并入第3章时，第3章取 5800–6600 字，平均每节约 1200 字。
- 变体 F（6 章）：绪论 1800、材料与方法 1800、实验一 2700、实验二 2700、综合讨论 1800、结论与展望 1200。
- 正文写到 15000 字时，第3章加一节或把 3.2 拆成两节，不加长单节。

## 各章写法

### 第1章 绪论

任务：把一个实际问题收窄成几个可以用实验回答的具体问题。

1.1 研究背景与意义
1. 从离研究对象最近的背景写起，给一到两个数字或事实，写明年份和范围。
2. 写这个问题带来的具体限制，例如效率低、损失大、稳定性差、机制不清。
3. 写现有处理方法或材料的不足，分两到三点。
4. 引出本文的研究对象和切入点。
5. 写意义：理论意义写补充了哪一关系的证据，应用意义写为哪种选择或评价提供依据。

1.2 国内外研究现状
1. 按两到三条主题线组织，例如"对象或材料""处理或改性策略""作用机理"。按主题分比按国内、国外分段更常见。
2. 每条线先写已有的共同认识，再选两到四篇代表文献，写"对象、条件、指标、结论"。
3. 文献结论不一致时，写出对象、条件或测定方法上的差异。这些差异就是本文要控制的条件。
4. 最后一段归纳研究不足：已有研究覆盖了什么，还缺哪类证据，这个缺口影响哪个判断。
5. 比较维度多时用一张文献比较表。全文过半引用集中在本节。

1.3 研究目标、内容与技术路线
1. 一句话写总目标：以……为对象，研究……对……的影响及其机制。
2. 拆成两到三项研究内容，每项写对象、比较因素、测定指标和要回答的问题。内容写成"比较什么、判断什么"，不写成仪器清单。
3. 每项内容在第3、4章都有对应的节。
4. 画技术路线图：材料→处理或制备→表征与测定→结果比较→机理分析→结论。递进关系用箭头，并行测定用支路。
5. 最后一段写论文结构，每章一句。
- 配图 1 幅（技术路线图），可配表 1 张（文献比较表）。

### 第2章 材料与方法

任务：写清比较从何而来、每个数据怎么测、数据怎么变成判断，让读者能照着复做。

2.1 实验材料与仪器
1. 写研究对象的来源、规格或品种、批次和初始状态。材料类写原料纯度和厂家，食品类写产地和初始品质，生物类写品种、菌株、品系或细胞系。
2. 写主要试剂，列名称、规格、生产厂家。
3. 写主要仪器，列名称、型号、生产厂家、用途。
4. 动物或细胞实验写伦理审查编号和饲养或培养条件。
- 配表 1–2 张（试剂表、仪器表，可合并）。

2.2 实验设计与样品制备
1. 先写设计思路：自变量是什么，因变量是什么，哪些条件保持一致。
2. 写分组：对照组和各处理组的条件、样品编号规则、每组重复数。对照按本题要回答的问题设置，可以是空白、未改性样品、模型组或阳性对照。
3. 有多个因素时写清是单因素梯度、正交、响应面还是分阶段选择。
4. 写制备或处理过程，按实施顺序分步，每步写条件（温度、时间、浓度、转速、pH）。
5. 写样品进入测定前的保存和前处理方式。
6. 处理条件取自文献或预实验时，写明出处和确定标准。
- 配图 1 幅（制备或处理流程图），配表 1 张（实验设计表：组别、编号、处理条件）。

2.3 测定指标与数据处理
1. 按第3章结果出现的顺序介绍指标。指标分两到三类时用三级小节，每类一个小节。
2. 每个指标写：测什么、反映什么、方法来源、仪器和主要参数。
3. 结构表征写测试条件，例如扫描范围、加速电压、波数范围。
4. 计算指标给公式，编号，逐个解释符号和单位，写清基准和分母。
5. 需要标准曲线的测定写标准品、线性范围和回归方程。
6. 数据处理写：每组独立重复数和每个样品的测定次数，结果的表示形式（平均值±标准差），统计方法（单因素方差分析加多重比较、t 检验、回归或模型拟合），软件和版本，显著性水平及图中标记规则。
7. 技术重复和独立重复分开写。拟合模型写参数估计方法和拟合优度指标。
- 配公式 3–8 个，可配表 1 张（指标与方法汇总表）。

### 第3章 实验结果与分析

任务：按研究问题逐项给出数据，说明处理产生了什么效应、效应多大、随条件怎样变化。

每个结果节用同一顺序写：
1. 一句话写本节比较什么、指标反映什么。
2. 指向图表，写总体趋势。
3. 给代表数值：处理组与对照组的值、差值或变化率，标明相对哪一组。
4. 写统计结果：组间差异是否显著。
5. 用一到两句给出初步解释。
6. 一句话收束本节结论，写明条件范围。

3.1 样品表征或对象状态确认
1. 写制得的样品或处理后的对象是否满足后续比较的条件。
2. 材料类按形貌、物相、组成、表面官能团的顺序写，每种表征写读出的关键特征（峰位、晶面、元素含量、粒径），并与对照样品比较。
3. 生物类写胁迫或造模是否生效，例如表型变化、生长指标、模型组与正常组的差异。
4. 食品和天然产物写组分或基本理化性质。
5. 每种表征回答一个问题，几种表征互相印证后再下结论。
- 配图 2–4 幅（SEM 或显微图、XRD 或 FTIR 谱图、表型照片），图像标比例尺。

3.2 处理对核心指标的影响
1. 按核心问题写一到两个结果块。同时报告几项并列指标时，每项一个三级小节。
2. 先写处理组与对照组的总体差异，再写各组之间的差异。
3. 写变化率时写清基准，百分比和百分点分开写。
4. 正文挑出支撑判断的数值：最大值、最小值、转折点、显著差异，不逐格复述表格。
5. 差异不显著或方向相反的结果照样报告，写明它说明了什么。
- 配图 2–3 幅（柱状图或曲线，带误差线和显著性标记），可配表 1 张（关键数值表）。

3.3 因素水平或时间变化的影响
1. 单因素梯度：写指标随因素变化的方向、转折点和平台区，"最佳条件"限定在考察范围内。
2. 时间序列：先写整体变化轨迹，再按阶段比较。
3. 正交或响应面：写极差或方差分析结果、各因素的主次顺序、最优组合，再写验证试验的结果和与预测值的误差。
4. 两因素设计先写主效应，再写交互作用。
5. 动力学或等温线等模型拟合：列拟合参数和 R²，比较几个模型，选出拟合较好的模型并说明其含义。
- 配图 2–3 幅（趋势曲线、响应面图、拟合曲线），配表 1–2 张（因素水平表、方差分析表或拟合参数表）。

3.4 稳定性、重复使用或验证实验
1. 写稳定性或重复使用的测试条件和次数。
2. 写初始值和末次值，以及保持率。
3. 写实际样品或外部条件下的验证结果，与实验室条件下的结果比较。
4. 本节末尾用一段收束全章：按研究内容逐项写已确定的结果，并引出第4章要解释的问题。
- 配图 1–2 幅（循环曲线、验证结果对比图）。

### 第4章 机理分析与讨论

任务：解释第3章的效应为什么出现、在什么条件下成立，并与已有研究比较。

4.1 结构或组成与性能（效应）的关联
1. 把第3章的表征结果和性能结果放在一起看，写哪些结构或组成变化与哪些性能变化同步出现。
2. 用相关分析、主成分分析或对照组比较说明关联的方向和强弱。
3. 写清哪些关联由本文数据直接支持，哪些需要更多证据。
4. 植物和模型类写表型、生理指标和分子指标之间的对应。
- 配图 1–2 幅（相关性热图、主成分图或对比图）。

4.2 作用机制分析
1. 写本节要解释的现象，来自第3章哪几项结果。
2. 给出机制证据：处理前后的谱图对比、价态变化、自由基捕获实验、基因表达、通路富集或模型拟合参数。
3. 按"现象→证据→推断"的顺序写，每个推断对应一项证据。
4. 画一幅机制示意图，图中区分本文测得的关系和推测的关系。
5. 相关性、表达变化和分子对接写成"提示""可能参与"；做了验证实验的写成"表明""证实"。
- 配图 1–2 幅（机理前后对比图、机制示意图）。

4.3 与已有研究的比较及适用条件
1. 选三到五篇同类研究，列一张对比表：对象、条件、关键指标、结果。
2. 写本文结果与它们相同和不同的地方，用对象、条件或测定方法的差异解释不同之处。
3. 写结论的适用条件：对象范围、浓度或温度范围、时间尺度、实验室或实际介质。
4. 本节末尾用一段收束全章：写机理分析得到的主要判断，以及支持它的证据。
- 配表 1 张（与已有研究的对比表）。

### 第5章 结论与展望

5.1 主要结论
1. 开头一句写研究对象和比较范围。
2. 按研究内容的顺序写三到五条结论，与第1章研究内容一一对应。
3. 每条先给判断，再给关键数值和条件，例如"在……条件下，……的……达到……，比对照提高……%"。
4. 结论写成从数据得到的认识，不写成"完成了某测定"。
5. 测定结果和机理推断分开写，用词与正文一致。
6. 学校要求时加一段创新点，写相对已有研究的增量。

5.2 研究局限与展望
1. 写两到三项局限，每项写"本文研究到哪里、影响哪个判断、需要补什么证据"。例如样品体系单一、考察时间短、机制证据停留在关联层面、只在实验室条件下测试。
2. 每项局限对应一个后续方向：扩大对象范围、延长观察时间、补做验证实验、在实际场景中测试。

## 摘要写法

中文摘要 400–600 字，关键词 4–5 个，覆盖研究对象、处理或比较因素、主要方法和机制主题。

句子功能序列（8–11 句）：
1. 背景与问题：研究对象的重要性和现有不足，1–2 句。
2. 目标：本文要确定的关系，1 句。
3. 方法：研究对象、处理或比较因素、主要测定手段，1–2 句。
4. 结果：按研究内容顺序写方向、关键数值和条件，3–4 句。
5. 机理：解释证据和支持程度，1 句。
6. 结论与意义：判断及适用范围，1 句。

摘要里的数值与正文同值、同单位、同对照组。学校要求"目的、方法、结果、结论"四段式时，把对应句子放进四段。英文摘要与中文逐句对应。

## 质量要点

下面各条是高质量论文里也常出的问题，写作和自查时逐条核对。

1. 建一张"研究内容—组别—指标—图表—结论"对照表。每项研究内容都有对应的方法、结果节和结论条，每条结论都能指回一张图或一张表。
2. 同一个数值在摘要、正文、图表、小结和结论中保持一致，包括单位和小数位数。改动一个数据后，同步更新所有出现的位置。
3. 变化率写清基准：相对哪一组、哪个时间点。百分比增减按"（处理−对照）/对照 × 100%"计算，写入前复算一次；两个百分数相减写"……个百分点"。
4. 样品编号、组别名称、缩写在方法、正文、图例、表格和结论中写法一致，首次出现时给全称。
5. 方法中的分组、重复数和处理条件与结果图表中的组别和 n 值一一对应。条件在不同阶段发生变化时，在方法和结果中都写明。
6. 统计信息前后一致：方法、正文、图注中的 n 值、误差形式、显著性水平和标记符号含义相同。独立重复和技术重复分开写。
7. 正文对"显著""不显著"的描述与统计检验结果一致，图上的字母或星号与正文相符。
8. 实验设计名称与实际方法一致：L9(3⁴) 正交表 9 组，三因素三水平 Box-Behnken 响应面 17 组。优化得到的最优条件落在考察范围内，并有验证试验。
9. 公式的符号、单位与正文一致，计算指标按公式能从表中数据复算出来。
10. 措辞与证据强度对应：测得的结果写"测得""观察到"，多项证据一致时写"表明"，只有相关、表达变化或对接结果时写"提示""可能"。
11. 机制示意图中的每个箭头都能在正文找到对应证据，推测关系用不同线型标出。
12. 差异不显著、方向相反的结果在正文中报告，并写明它对结论的限定。
13. 结论写明适用条件：实验室条件、所用对象和浓度或温度范围。细胞和动物结果不直接写成人体效果。
14. 图、表、公式按章连续编号，不重号、不跳号。正文引用的编号与题注一致，中英文题注同号同义。
15. 绪论中的研究内容、技术路线图和论文结构与实际章节一致。
16. 展望中的每一项对应 5.2 写出的一项局限。
