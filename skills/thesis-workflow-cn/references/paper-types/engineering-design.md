# 工程设计 写作模板

## 适用范围

判断依据：论文的主要成果是一个部件、一台装置或一套工程系统的设计方案，正文的核心是“设计要求 → 方案选择 → 设计计算与选型 → 校核或仿真 → （试验验证）”。如果主要成果是软件系统，归“系统设计与实现”；如果主要成果是算法或模型的改进，归“算法模型改进”。

包含的子类：

- 机械：农业机械与农产品加工装备，写法是“关键部件设计 → 离散元或其他仿真 → 台架或田间试验”；一般机械结构，包括工程机械、机器人、换热器，写法是“结构设计 → 有限元/数值分析 → 优化”。
- 电气：装置与电路设计、变电站工程设计。
- 土木建筑：只在变体里写差异。
- 化工：本模板不覆盖。

本科规模：设计对象定为一个部件或一套装置，工作量以设计计算、选型校核和图纸为主，仿真和试验按条件取舍。

## 章节骨架

主骨架按机械类的通用流程写。正文 5–6 章。

**第 1 章 绪论**（必有）
- 1.1 研究背景与意义（必有）
- 1.2 国内外研究现状（必有）
- 1.3 主要研究内容（必有）
- 1.4 技术路线（必有，多数论文配技术路线图）

**第 2 章 总体方案设计**（必有；方案论证可单独成章，也可作为本章首节）
- 2.1 设计要求与主要技术指标（常见）
- 2.2 方案比较与选择（必有）
- 2.3 总体结构与工作原理（必有）
- 2.4 主要技术参数（常见）
- 2.5 本章小结（必有）

**第 3 章 关键部件设计计算**（必有）
- 3.1–3.n 各关键部件设计，一个部件一节（必有）
- 动力与传动计算选型（常见）
- 3.x 本章小结（必有）

**第 4 章 校核与仿真分析**（必有）
- 4.1 强度、刚度校核（理论计算或有限元，常见）
- 4.2 模态分析（常见）
- 4.3 运动或工作过程仿真（常见）
- 4.4 参数分析与优化（常见于结构类）
- 4.5 本章小结（必有）

**第 5 章 样机试制与试验**（常见；本科有条件时写，无条件时删去本章，把验证内容并入第 4 章）
- 5.1 样机试制
- 5.2 试验方案与评价指标
- 5.3 试验结果与分析
- 5.4 本章小结

**第 6 章 结论与展望**（必有）
- 6.1 结论
- 6.2 展望

**变体**

- 农机类：第 2 章前加“作业对象/物料特性测定”，可单独成章，也可作为设计章或仿真章的一节。第 4 章以离散元仿真为主，常带单因素加响应面优化。试验章基本都有，分台架和田间两层。
- 结构仿真优化类（工程机械、减速器、AGV 等）：第 3 章改为“工况与载荷分析”（典型工况 → 受力 → 铰点载荷表），第 4 章改为“有限元分析”（找危险工况和薄弱部位），第 5 章改为“结构优化与复核”（变量 → 目标约束 → 优化 → 圆整 → 复算）。实物试验较少。
- 机器人/机电类：第 3 章含“运动学分析”（D-H 参数、正逆解、工作空间）。控制系统写成一节或一章，内容是硬件框图、选型、I/O、程序流程。试验是样机功能测试。
- 换热器/热工类：第 2 章含“理论基础与评价指标”。第 3 章是热力计算（热负荷 → 物性 → 关联式 → 面积 → 管长管数 → 压降）。第 4 章是数值模拟，含网格独立性检验和与文献数据的对照。
- 电气：
  - 工程设计型：第 2 章写“工程概况与现场调研”（规模、主接线、土壤与气象条件），第 3 章按规范逐级计算并校核限值，第 5 章可写“施工与运行技术措施”代替试验。
  - 装置型：第 3 章写硬件电路与程序设计，第 5 章写室内与现场功能测试。
- 土木建筑：硕士论文的顺序是“材料或构件试验 → 有限元参数分析 → 设计方法与算例”，试验在设计之前。本科常见做法是“结构选型 → 荷载计算 → 内力计算 → 截面设计与规范验算”（补充）。

## 字数分配

按正文 12000 字分配。本科压缩绪论和理论推导，把篇幅给设计计算。

| 章 | 本科参考字数 | 浮动范围 |
|---|---|---|
| 绪论 | 2000 | 1600–2500 |
| 总体方案设计 | 1800 | 1400–2200 |
| 关键部件设计计算 | 3800 | 3000–4500 |
| 校核与仿真分析 | 2300 | 1800–3000 |
| 样机试制与试验（可选） | 1500 | 1000–2000 |
| 结论与展望 | 600 | 400–800 |

- 不写试验章时，把 1500 字分给第 3 章（约 +800）和第 4 章（约 +700）。
- 农机类加物料特性测定时，从第 2、3 章各匀出约 500 字，写成 1000 字左右的一章或一节。
- 正文重心在中间三章。

## 各章写法

### 第 1 章 绪论

任务：说明为什么要设计这个对象，已有装置和方法做到哪一步，本文要设计什么、按什么路线做。

**1.1 研究背景与意义**
1. 用产业规模、政策或工程需求写一段背景。
2. 写现有作业方式或现有装置的问题，例如效率低、损伤大、适应性差、能耗高、可靠性不足。
3. 收窄到所研究的对象，说明它是解决问题的关键部件或装置。
4. 用一两句写意义，落到工程应用。
- 配图 0–1 幅（对象照片或应用场景）。

**1.2 国内外研究现状**

有三种组织方式，按题目选一种：
- 按技术线分 2–3 条，每条内部先国外后国内。例如整机现状、关键部件现状、分析方法现状。这种写法最常见。
- 把“装备/产品现状”和“设计分析方法现状”分开写。结构类常用。
- 先给一张类型比较表（结构、原理、优缺点），再分国内外展开。

步骤：
1. 每个实例写“对象 → 结构或方法 → 效果 → 局限”。
2. 每条线末尾用两三句归纳已有成果和不足。
3. 最后一段把不足集中成 2–3 条，作为本文设计的出发点。
- 配图 2–4 幅（代表装置图），可配 1 张类型比较表。引用集中在本节。

**1.3 主要研究内容**
1. 按后文章节顺序列 4–5 项工作。
2. 每项写对象、方法、输出。
3. 说明前一项的输出怎样成为后一项的输入。

**1.4 技术路线**
1. 画一幅技术路线图：设计要求 → 方案 → 计算 → 校核/仿真 → 试验 → 结论。
2. 在图中标出“不满足要求时返回修改”的反馈箭头。
3. 文字只作简短说明。

### 第 2 章 总体方案设计

任务：把使用需求转成设计要求，比较方案，确定总体结构和主要参数。

**2.1 设计要求与主要技术指标**
1. 写作业对象和工况：尺寸、负载、速度、环境、安装空间。农机类先写农艺要求，例如株行距、种植模式。
2. 把需求逐条转成可量化指标，例如生产率、负载、行程、合格率、功率上限。
3. 列技术指标表。后文的选型、校核和试验指标都回扣这张表。
- 配表 1 张。

**2.2 方案比较与选择**
1. 提出 2–3 个总体方案或关键部件类型。
2. 各配结构示意图，写工作方式。
3. 按同一组维度比较：功能、可靠性、适应性、结构复杂度、制造难度、成本、维护。
4. 给出选择理由。用定性比较表即可。
- 配图 2–3 幅，配表 1 张（方案比较表）。

**2.3 总体结构与工作原理**
1. 给整机或装置的结构图，各部件标序号。
2. 按序号写各部件功能。
3. 沿物料流或动力流写一个完整工作循环。
4. 说明本文设计范围，以及与外部设备的接口。
- 配图 1–2 幅（结构图、传动原理图）。

**2.4 主要技术参数**
1. 汇总外形尺寸、工作速度、功率、生产率等。
2. 列表，并说明来源（计算、标准或经验）。
- 配表 1 张。

**2.5 本章小结**
用 3–4 句回收：设计要求、所选方案、总体结构，并引出下一章要计算的部件。

### 第 3 章 关键部件设计计算

任务：对 2–4 个关键部件逐一确定结构和尺寸，完成动力与传动选型。这是本科论文的主体。

**每个关键部件一节，步骤固定：**
1. 写部件的功能要求，并对应第 2 章的技术指标。
2. 做类型比较与选型。可以简写，一两句给出理由。
3. 给出结构组成，配结构图。
4. 由运动或受力分析推导关键尺寸：
   - 画受力简图或运动简图，列出简化假设；
   - 写平衡方程、运动方程或经验公式，公式编号，并解释符号；
   - 代入参数求出结果。
5. 确定参数取值，写清取舍理由，例如“过小会……，过大会……，故取……”，并按标准系列圆整。
6. 给出三维模型或结构图（补充：本科可附零件图、装配图编号）。
- 每节配图 1–3 幅（结构图、受力图、轨迹曲线），配公式 4–10 个，可配参数表 1 张。

**动力与传动计算选型（常见）：**
1. 按最不利工况计算阻力或负载。
2. 由负载求功率、扭矩，并计入效率和安全系数。
3. 列候选电机、减速器、链/带、轴承的型号与参数。
4. 选型时写明“额定值 ≥ 计算值 × 系数”的核对过程。
5. 写传动路线，配传动简图。
- 配图 1 幅，配表 1–2 张（选型参数表）。

**计算的写法（补充）：** 每项计算按“计算项目 → 依据（公式、手册、标准）→ 代入 → 结果 → 结论”五步写，使读者可以复算。设计依据写明手册名称和版次，或标准编号。

**本章小结：** 逐个部件列出确定的主要尺寸和选型结果，并说明哪些需要下一章校核。

### 第 4 章 校核与仿真分析

任务：检查第 3 章的设计是否满足强度、刚度、振动和工作性能要求。必要时改进后再查一次。

**4.1 强度与刚度校核**
1. 选择校核对象：受力最大或结构最薄弱的零件。
2. 说明计算方法。本科可用材料力学公式校核，也可用有限元。
3. 用有限元时依次写：
   - 几何简化（删去小孔、倒角等小特征）；
   - 材料参数表；
   - 网格类型与尺寸；
   - 约束与载荷，载荷来自第 3 章计算。
4. 给出应力和位移云图，写最大值与位置。
5. 用“许用应力 = 屈服强度 / 安全系数”判断是否满足要求。
6. 不满足时加厚或加筋，修改后重新计算，列修改前后对比表。
- 配图 2–4 幅（模型、网格、云图），配表 1–2 张。

**4.2 模态分析（常见）**
1. 设置约束，求前 6 阶固有频率与振型。
2. 列出外部激励频率：电机转速、工作频率、路面激励等。
3. 比较二者，判断是否避开共振。
- 配图 1–2 幅，配表 1 张（频率对比表）。

**4.3 运动或工作过程仿真（常见）**
1. 说明仿真目的，并给出软件、模型简化、运动副与驱动设置。
2. 输出关键点轨迹、速度或工作过程结果。
3. 与理论计算对照，列误差。
- 农机类做离散元仿真时依次写：
  - 颗粒或物料模型（参数来自实测或文献）；
  - 接触模型与参数表；
  - 仿真设置（步长、时长）；
  - 评价指标定义；
  - 单因素仿真，确定因素范围。

**4.4 参数分析与优化（常见于结构类，有条件时写）**
1. 选设计变量及上下限，设定目标（如质量最小）和约束（应力、位移、频率）。
2. 用正交或响应面方法安排计算方案。
3. 拟合回归模型，分析各因素影响。
4. 求出较优参数组合，按加工精度圆整。
5. 用圆整后的尺寸重新建模复算，列优化前后对比表。
- 配图 2–3 幅（单因素曲线、响应面图），配表 2–3 张（方案结果表、方差分析表、对比表）。

**本章小结：** 分别写校核结论、频率结论、仿真结论和优化结果。说明结论对应的工况范围。

### 第 5 章 样机试制与试验（有条件时）

任务：用实物检验设计。

**5.1 样机试制**
1. 写加工方式、材料、装配要点。
2. 给样机照片，列主要参数。
- 配图 1–2 幅。

**5.2 试验方案与评价指标**
1. 写试验目的、地点、时间、对象状态（如品种、含水率、工况）。
2. 列仪器设备及精度。
3. 定义评价指标，给出计算公式，注明依据的标准编号。
4. 写试验方案，有两种做法：
   - 用设计或优化得到的参数直接验证；
   - 安排单因素和响应面/正交试验，在试验中寻优。
5. 规定重复次数，常为 3–5 次。
- 配图 1–2 幅（现场或台架照片），配表 1–2 张（因素水平表、仪器表）。

**5.3 试验结果与分析**
1. 列原始结果表，并取平均值。
2. 有多因素试验时：回归方程 → 方差分析 → 响应面图 → 最优组合 → 验证试验。
3. 与计算或仿真值比较，给出相对误差。
4. 分析误差来源，例如模型简化、制造误差、现场条件。
5. 对照技术指标或标准判断是否达标。
- 配图 2–3 幅，配表 2–3 张。

**5.4 本章小结：** 分别写试验条件、主要结果、是否满足设计要求，以及试验覆盖的范围。

### 第 6 章 结论与展望

**6.1 结论**
1. 按研究内容逐条写，3–5 条。
2. 每条写“完成了什么 + 关键数值”，例如确定的主要尺寸、选型、校核余量、试验指标。
3. 仿真预测值与实测值分开写。

**6.2 展望**
1. 写 2–3 条。
2. 每条对应本文实际没有覆盖的内容，例如未制作样机、只做了台架试验、未考虑振动、工况单一、控制方式简单。

## 图表配置

全文图 15–25 幅、表 8–12 张、公式 20–40 个，参考文献 15–30 篇，外文占 20%–40%。

|---|---|---|

| 总体方案设计 | 3–5（方案示意图 2–3、总体结构图 1、传动原理图 1） | 2–3（技术指标表、方案比较表、主要参数表） | 0–3 |

| 样机试制与试验 | 3–5（样机照片、试验现场、响应面或结果曲线） | 2–4（因素水平表、结果表、方差表、对比表） | 2–5 |

## 摘要写法

中文摘要 300–500 字，关键词 3–5 个。

句子功能序列：
1. 背景与问题（1–2 句）：所研究对象的应用场景，以及现有方式存在的问题。
2. 研究目标（1 句）：本文设计了……。
3. 总体方案（1 句）：采用……结构，由……组成，工作原理是……。
4. 设计计算（1–2 句）：确定了……的关键参数，选用了……。
5. 校核或仿真（1 句）：……分析表明，最大应力为……，满足……要求。
6. 试验结果（1 句，有试验时）：试验表明……指标为……，满足……。
7. 结论或意义（1 句）：该设计可为……提供参考。

英文摘要与中文逐句对应。摘要中的数值必须与正文一致，并写明是预测值还是实测值。

## 句型框架

**绪论**
1. 随着……的发展，……对……的要求不断提高。
2. 目前……主要采用……方式，存在……和……等问题。
3. ……是影响……的关键部件，其性能直接决定……。
4. ……设计了……，实现了……，但在……条件下仍存在……。
5. 现有研究多集中于……，针对……的研究较少。
6. 本文以……为研究对象，按照……的技术路线开展……设计。

**总体方案设计**
7. 根据……的工作要求，确定……的主要技术指标如表……所示。
8. 方案一采用……，优点是……，但……；方案二采用……，……。
9. 综合比较……、……和……，选用方案……。
10. 该装置主要由……、……和……组成，各部件的作用是……。
11. 工作时，……经……进入……，在……作用下完成……，最后由……排出。
12. 本文的设计范围为……，……部分采用现有……。

**关键部件设计计算**

## 质量要点

下面各条是高质量论文里也常出的问题，写作和自查时逐条核对。

1. 同一个数值在摘要、正文、表格、小结、结论中保持一致，包括精度位数。改动任何计算结果后，同步更新所有出现的位置。
2. 每个物理量带正确单位，同一量在全文用同一单位（mm 与 cm、kg/s 与 g/s、kJ 与 kW 不混用）。公式代入前先核对量纲。
3. 图、表、公式按章连续编号，不重号、不跳号。正文引用的编号与实际题注一一对应。
4. 预测值、仿真值、实测值分开表述。摘要和结论报告最终性能时，使用圆整后参数的验证结果。
5. 优化后的参数先圆整，再用圆整值重新计算。对比表注明每一列来自哪个阶段。
6. 试验设计的名称与实际方法一致：17 组三因素三水平是 Box-Behnken 响应面试验，9 组 L9 表才称正交试验。
7. 优化结果落在试验因素的取值范围内。超出范围时说明理由，或补做试验。
8. 声称“满足要求”前，逐项核对计算值与约束值。超出限值时如实写明，并给出处理措施。
9. 区分相对误差和百分点差：两个百分数相减写“相差……个百分点”，相对误差按“|测−算|/算 × 100%”计算。
10. 正文对显著性的描述与方差分析表的 P 值一致。只描述主效应时，写明“主效应”。
11. 模态分析同时列出固有频率和外部激励频率，再判断是否共振。频率落入激励范围时，写明风险与对策。
12. 选型时，所选元件的额定值不低于计算值；校核用的材料强度与材料参数表一致。
13. 结论中的结构描述（传动方向、层数顺序、部件名称）与正文设计章一致。写完后对照设计章逐条核对。
14. 绪论中“本文共……章”和技术路线图的章节标注与实际目录一致。
15. 按试验条件写结论的适用范围：台架结果写“台架条件下”，室内结果写“室内条件下”，仿真结论写“仿真条件下”。
16. 根据试验结果修改了结构时，对改进后的结构补做验证，或在展望中写明尚待验证。
17. 百分比增幅、减幅按“（新−旧）/旧”计算，写入前复算一次。
